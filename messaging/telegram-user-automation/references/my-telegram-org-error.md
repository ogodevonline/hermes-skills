# my.telegram.org отдаёт ERROR при создании приложения

Ошибка без деталей — просто «ERROR», без текста и кода. Ниже — что известно из разбора; **на этом аккаунте ни один пункт не подтверждён как решающий**, применялись они вместе.

## Вероятные причины

1. **Подчёркивание в Short name.** `hermes_app` — подчёркивание; нужны только латиница и цифры, UpperCamelCase: `HermesApp`. App title — так же, без пробелов и спецсимволов.
2. **Пустой Description.** Одной строки мало, нужен развёрнутый текст (40+ символов).
3. **VPN.** Telegram сверяет IP со страной номера: российский номер из-под зарубежного VPN = молчаливый ERROR. Без VPN работает.
4. **URL.** Оставлять рабочий сайт (`https://example.com`), не localhost и не случайный набор.
5. **Кэш, куки, расширения.** Помогает Chrome в инкогнито или другой браузер, AdBlock выключить.
6. **Аккаунт должен быть живым** — свежерегистрированный номер без активности проходит хуже.

Сводный разбор причин: https://habr.com/ru/articles/923168/

## Если номер уже использовался

Официальная документация (https://core.telegram.org/api/obtaining_api_id): «each number can only have one api_id connected to it». Повторно создать приложение на тот же номер нельзя — существующие `api_id`/`api_hash` показываются на https://my.telegram.org/apps.

## Обходной путь

API ID — идентификатор приложения, а не аккаунта: «This API ID and hash is the one used by your application, not your phone number. You can use this API ID and hash with any phone number or even for bot accounts» — https://docs.telethon.dev/en/stable/basic/signing-in.html. То есть приложение можно завести на второй номер, а авторизоваться основным аккаунтом.

## Альтернатива без api_id: веб-клиент

`https://web.telegram.org/k/` открывается с этого сервера (проверено). Вход по номеру: на стартовом экране кнопка **LOG IN BY PHONE NUMBER** → ввод номера (страна подставляется) → код приходит в Telegram → 2FA при наличии.

Техническая деталь: кнопка — `span` внутри `label`, обычный JS-`click()` её не берёт; нужен настоящий клик по координатам. Алгоритм: `scrollIntoView({block:'center'})` (кнопка может быть ниже viewport), затем `getBoundingClientRect()` → `click_at_xy(x, y)` по центру.

Веб-клиент даёт полный доступ к аккаунту, как новое устройство: владельца предупредить и напомнить про «Устройства → завершить сессию».
