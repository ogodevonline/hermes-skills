# Low-Resource Language Models Skill

Закрывает задачу «научи нейронку понимать язык X» для языков с малой ресурсной базой (каракалпакский, узбекский, казахский, любые <5 млн носителей): найти готовые открытые модели и корпуса, проверить качество живьём, и только потом считать деньги на дообучение. Не покрывает перевод общего назначения и обучение LLM с нуля — там нужен другой подход.

## When to Use

- «Научи понимать язык X», «цифровой администратор на каракалпакском», голосовой ассистент/бот на редком языке.
- Нужно оценить, стоит ли своё обучение, и сколько это будет стоить.
- Нужны ASR (аудио→текст), MT (перевод), TTS (озвучка), OCR (документы) для малого языка.

## Prerequisites

- `~/.cargo/bin/web-tools` — обычный веб-поиск (правила в навыке `web-search-scraper`).
- `python3` + `requests` (есть системно) — скрипт live-проверки.
- `HF_TOKEN` — опционален, но снимает лимит ZeroGPU у демо-спейсов и открывает gated-датасеты.
- GPU не нужен ни для разведки, ни для проверки: и то и другое делается через HTTP API.

## How to Run

```bash
# 1. Разведка по HuggingFace API (не web-search!)
curl -s "https://huggingface.co/api/models?search=karakalpak&limit=50"
curl -s "https://huggingface.co/api/models?filter=kaa&limit=50"          # ISO 639-3 код языка
curl -s "https://huggingface.co/api/datasets?search=karakalpak&limit=50"
curl -sL "https://huggingface.co/<repo>/raw/main/README.md"              # WER/BLEU, часы, лицензия, железо

# 2. Реальные семплы теста без скачивания корпуса (аудио приходит base64)
curl -s "https://datasets-server.huggingface.co/rows?dataset=<ds>&config=default&split=test&offset=0&length=2"

# 3. Live-проверка ASR-модели через Gradio Space + подсчёт WER
python3 scripts/verify_asr_space_wer.py \
    --space https://<owner>-<space>.hf.space \
    --api-name transcribe \
    --dataset <dataset-id> --split test --n 10 \
    --text-field raw_text --token "$HF_TOKEN"
```

## Quick Reference

| Что искать | Как |
|---|---|
| Модели по языку | `/api/models?search=<lang>`, `?filter=<iso639-3>` |
| Всё у одного автора | `/api/models?author=<user>` |
| Метаданные модели | `/api/models/<repo>` → `cardData`, `tags`, `siblings` |
| README с метриками | `https://huggingface.co/<repo>/raw/main/README.md` |
| Семплы датасета | `datasets-server.huggingface.co/rows?...` |
| Демо модели | `/api/spaces?search=<lang>` → Gradio Space |
| CPU-вариант | ищи `*-GGUF` репозиторий (q4 ≈ 2 ГБ на 3B модель) |

## Procedure

1. **Разведка.** HF API по имени языка, по ISO-тегу и по автору + `web-tools search` для статей (arXiv/WMT/конференции) — там бенчмарки и описание корпусов.
2. **Читай карточки, а не догадывайся.** В README почти всегда есть: метрика (WER/BLEU), часы данных, лицензия, **железо и время обучения**. Это дешевле, чем гонять обучение самому.
3. **Сравнивай на одном тест-сплите.** Ищи в README лучшей модели таблицу сравнения с конкурентами (в ней видны zero-shot модели и чужие fine-tune'ы на том же тесте).
4. **Live-проверка обязательна.** Гони 5-10 реальных уттер/строк из тест-сплита через Space или свой инференс и посчитай метрику сам. Выдача поиска — кандидаты, не подтверждение.
5. **Только теперь считай стоимость.** Обучение = (замеренные часы GPU) × (цена карты/час). Дообучение под свой домен — то же самое с новыми данными.
6. **Отдай пользователю стек целиком** (слух → перевод → логика → голос), а не список ссылок.

## Pitfalls

1. **ZeroGPU-спейсы лимитируют анонимные вызовы.** После 2-3 прогонов SSE возвращает `You have exceeded your ZeroGPU runs limit` — это не сломанный спейс, а квота. Нужен HF-токен (`--token`). Не докладывай «демо не работает».
2. **Не выдавай результаты поиска за результат.** Пользователь прямо ругает за непроверенное — см. web-search-scraper. В отчёте помечай ✅ проверено живьём / ⚠️ только по карточке.
3. **WER из карточки ≠ WER на твоих данных.** У моделей одного языка разброс 9% → 97% из-за in-domain/out-of-domain теста. Всегда проверяй, на каком сплите мерили.
4. **Письменность и орфография.** Каракалпакский: латиница и кириллица параллельно, реформы 1995/2009/2016, буквы `á ǵ ı ń ó ú`. Перед подсчётом метрик — NFC, lower, убрать пунктуацию; кириллицу транслитерировать в латиницу, иначе CER раздувается.
5. **Google Translate малые языки не поддерживает** (каракалпакского там нет). Считай только на открытых NLLB/MADLAD-производных или сервисах из статьи.
6. **Не начинай с обучения.** Для большинства редких языков уже есть SOTA-модели от энтузиастов и университетов. Обучение с нуля оправдано только под свой домен/диалект.
7. **GPU бери на часы.** RunPod RTX 4090 — от $0.34/ч (Community), Secure Cloud $0.74/ч. Kaggle — бесплатные T4×2 16 ГБ, ~30 ч/неделю, сессия ≤9-12 ч. Vast.ai — маркетплейс, фиксированной цены нет, проверяй живой оффер.
8. **`web-tools extract` не имеет `--chars`** — только `--timeout/-j/-r/-p`; при передаче лишнего флага бинарник падает с `unexpected argument`.
9. **`curl | python3`** может триггерить security-approval. Нужна тихая сессия — пиши ответ в файл и парсь отдельным вызовом.

## Verification

- Разведка подтверждена API-ответом (не сниппетом поиска): есть `modelId`/`id`, `lastModified`, размер корпуса.
- Хотя бы одна модель проверена живьём: скрипт вернул непустые гипотезы и посчитанный WER/BLEU против эталона.
- Стоимость посчитана из **заявленных в карточке** часов обучения × текущей цены аренды, а не из оценки «на глаз».
- В ответе указано, что проверено живьём, а что взято из карточки, и приведены ссылки на первоисточники.
