# Структура профиля пользователя в Obsidian

Когда нужно сохранить информацию о пользователе (GitHub, резюме, проекты, навыки, биография) в Obsidian vault, используй эту структуру.

## Структура папки

```
~/hermes-vault/Areas/Profile/
├── index.md              # Карточка: ФИО, контакты, образование, языки
├── tech-stack.md         # Технологический стек
└── experience/
    ├── _index.md         # Оглавление со ссылками на все проекты
    ├── project-name.md   # Один файл на проект
    └── ...
```

## Содержание файлов

### index.md
- ФИО, телефон, email, Telegram, GitHub, сайт
- Компания/работа
- Обо мне (кратко)
- Образование (вузы, курсы)
- Языки
- Биография (до-IT опыт, спорт, хобби) — если релевантно
- Ссылки на tech-stack.md и experience/_index.md

### tech-stack.md
- Языки программирования
- Фреймворки и библиотеки (backend, frontend, боты, ORM)
- Базы данных
- DevOps и инфраструктура
- Инструменты
- ML/AI (если есть)
- Методологии

### experience/_index.md
- Хронологический список проектов с ссылками на каждый файл
- Формат: `1. [[Areas/Profile/experience/project-name|Название проекта — Годы]]`

### experience/<project-name>.md
Каждый файл проекта:
- Название проекта
- Период работы
- Роль (Full-Stack / Backend / Frontend)
- Компания
- Описание (2-4 предложения)
- Задачи и достижения (буллеты)
- Технологии (через запятую)

## Источники данных

- GitHub профиль (README, pinned repos, contribution graph)
- GitHub репозитории (pyproject.toml, RESUME.md, README.md)
- Устная информация от пользователя
