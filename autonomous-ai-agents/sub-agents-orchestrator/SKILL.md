# Sub-Agents Orchestrator

Схема делегирования: **я (Hermes) = оркестратор**, суб-агенты = исполнители.

**Правила:**
- Суб-агенты **не видят память** и **не могут говорить с пользователем**
- Всегда передавай **весь контекст** в goal: даты, имена, пути, формат вывода
- Язык: если пользователь пишет по-русски — goal тоже на русском
- Результат суб-агента — **сырые данные**. Я форматирую и отдаю пользователю
- После делегирования — **проверяй результат**: суб-агент мог ошибиться

---

## Агент A: Worker (tasks, obsidian, hub)

**Роль:** сбор данных из локальных инструментов (быстро, без веба)

**Тулсет:** `terminal`, `file`
**Скиллы:** `personal-task-tracker`, `obsidian`, `hermes-hub`

**Когда использовать:**
- Собрать задачи на сегодня (`t list`)
- Проверить привычки (`t habits`)
- Записать/прочитать заметку в Obsidian
- Собрать дашборд hermes-hub
- Запустить локальный скрипт (планирование, аналитика)

**Пример делегирования:**
```
delegate_task(
    goal="Собери все задачи на сегодня из SQLite-трекера. Команды: t list, t status. Верни список с приоритетами [H][M][L]. Ответь по-русски.",
    toolsets=["terminal", "file"]
)
```

**Питфолл:** у Worker нет `web` — не проси его искать в интернете.

## Агент B: Searcher (web-search-scraper, crawl4ai, blogwatcher)

**Роль:** поиск и извлечение данных из интернета

**Тулсет:** `web`, `terminal`, `file`
**Скиллы:** `web-search-scraper`, `crawl4ai`, `blogwatcher`

**Когда использовать:**
- Поиск информации (события, места, цены, новости)
- Глубокий анализ сайта (OLX, Avito, маркетплейсы)
- Мониторинг фидов (blogwatcher)
- Сбор данных с нескольких источников

**Пример делегирования (поиск):**
```
delegate_task(
    goal="Найди информацию о [тема]. Используй web-search-scraper: uv run ~/.hermes/skills/search/web-search-scraper/scripts/search.py --query \"поисковый запрос\" --preview. Если нужно углубиться — crawl4ai. Ответь по-русски с ссылками.",
    toolsets=["web", "terminal", "file"]
)
```

**Пример делегирования (crawl4ai):**
```
delegate_task(
    goal="Проанализируй сайт [URL]. Используй crawl4ai: cd ~/.hermes/skills/search/crawl4ai/scripts && uv run python crawl.py --url \"[URL]\" --max-pages 3 --links-only. Верни список найденных объявлений с ценами и ссылками. Ответь по-русски.",
    toolsets=["web", "terminal", "file"]
)
```

**Важно:** Searcher может работать параллельно — запускай несколько копий для разных запросов.

**⚠️ Питфолл: web_extract тормозит!** Суб-агент может начать использовать `web_extract` (встроенная тулза) для каждого результата поиска, что занимает 1+ минуту на URL. **Явно запрещай web_extract в goal**, если суб-агенту нужны только быстрые факты:

```
❌ Плохо: "проверь погоду" → агент использует web_extract, 8 минут
✅ Хорошо: "проверь погоду. Используй ТОЛЬКО web_search для быстрого поиска. НЕ используй web_extract."
```

## Агент C: Education (english-lesson, python-road, ielts-prep)

**Роль:** генерация учебных материалов

**Тулсет:** `terminal`, `file`
**Скиллы:** `english-lesson`, `python-road`, `ielts-prep`

**Когда использовать:**
- Создать урок английского по теме
- Сгенерировать Python-упражнение
- Подготовить IELTS-задание
- Сохранить урок в Obsidian

**Пример делегирования:**
```
delegate_task(
    goal="Создай урок английского на тему [тема] уровня A2. Сохрани в Obsidian: ~/hermes-vault/English/lessons/[название].md. Верни краткое описание урока. Ответь по-русски.",
    toolsets=["terminal", "file"]
)
```

## Сценарии оркестрации

### Утренний бриф (параллельно)
```
1. delegate_task(Agent A: "собери задачи на сегодня, статус привычек. t list, t habits.")
2. web_search("погода Москва") ← **сам, а не через агента** — быстрее (2с vs 8мин)
3. ← получаю задачи от агента
4. Формирую бриф → отправляю пользователю
```

### Поиск домов в Нукусе
```
1. delegate_task(Agent B: "crawl4ai OLX Нукус дома до 280 млн")
2. ← получаю список объявлений с ценами и ссылками
3. Анализирую, показываю пользователю
```

### Вечерняя рефлексия
```
1. delegate_task(Agent A: "собери выполненные задачи за сегодня, статус привычек")
2. ← получаю данные
3. Запускаю evening-diary-brief (сам, не в суб-агенте — там диалог с пользователем)
```

## Ограничения

- Суб-агенты не могут делегировать дальше (`role="leaf"`, по умолчанию)
- Нет доступа к памяти пользователя — передавай всё в goal
- Суб-агенты не вызывают tools, которых нет в их toolsets
- Если суб-агент завис — будет timeout через 5 минут
- Результат суб-агента — **self-report**, проверяй его (файл создан? ссылка работает?)
