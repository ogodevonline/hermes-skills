# Session Context Provision for Sub-Agents

Когда суб-агенту (skill-improver, refactoring-guru) нужно понять ошибки из сессии:

## Проблема
Sub-agent (даже claude-sonnet-4.6) не может читать session_search — у него нет этого инструмента. Если дать ему только summary сессии, он пропустит важные нюансы и скажет «всё норм, правок не требуется».

## Решение: сохранить транскрипт сессии в файл

```bash
# 1. Собрать ключевые моменты сессии в файл
~/hermes-vault/сессия-YYYY-MM-DD.md

# Файл должен содержать:
# - Кто участвует (пользователь + агент)
# - Хронология: что сказал пользователь, что ответил агент
# - ЦИТАТЫ недовольства (с матом — сохранять как есть)
# - Какие ошибки совершил агент
# - Повторяющиеся паттерны
# - Текущее состояние системы (пути, профили, symlinks, SOUL.md)
```

## Правила
1. Файл сессии сохраняется в ~/hermes-vault/ — не в /tmp/
2. В теле задачи укажи агенту: «Прочитай ~/hermes-vault/сессия-YYYY-MM-DD.md»
3. Не пересказывай сессию в body задачи — это фильтрует детали
4. Не предписывай решение — просто предоставь контекст
5. После использования файл можно оставить в vault как историю

## Пример body задачи
```
Прочитай файл: ~/hermes-vault/сессия-2026-05-28.md
Там полностью расписана сессия — все ошибки дефолтного агента, все реакции пользователя.
Прочитай навыки и SOUL.md. Составь план. НЕ исправляй.
```
