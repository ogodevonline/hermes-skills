# Покупка готовых прокси (РФ и общий случай)

## Какой тип IP проходит на какую цель

| Целевой сайт / задача | Тип IP | Почему |
|---|---|---|
| Свои парсеры, госсайты, VK, Telegram, 2GIS, hh.ru | датацентр | хватает РФ-IP и обычного поведения |
| Wildberries, Ozon | ISP (провайдерский) или резидентский | облачные ASN в блэклистах; SmartCaptcha судит ещё и поведение |
| Avito, Auto.ru, Drom | ISP или резидентский | вместо капчи тихо отдают 404 — «объявление не найдено» при живом объявлении |
| CIAN | РФ ISP/резидентский | иностранные IP режутся целиком, московские и краснодарские выдачи разные |
| Мультиаккаунты, антидетект-браузеры | мобильный | датацентр-подсеть палится сразу |

Минимум для РФ-цели: московское время (UTC+3), `Accept-Language: ru-RU`, консистентный отпечаток браузера, РФ-IP. Убрать любой из четырёх — падает допустимый лимит запросов (особенно на WB/Ozon/CIAN/Yandex).

## Снятые со страниц провайдеров цены (перепроверять — меняются)

- **papaproxy.net** — Russian datacenter IPv4, «from $0.08 per IP/month», до 500 Мбит/с на прокси. Самое дешёвое из проверенных.
- **fineproxy.org** (страница Russia) — RU-датацентр на собственном ASN, трафик без лимита: «0,12 $ за адрес/мес» в пакете. Собственная ASN — не хостерская, поэтому WB/Ozon не матчат по списку облаков.
- **webshare.io/proxy-locations/ru** — заявлено «from $0.029/IP» и «$0.0179/IP» в крупных планах; RU-резидентские от $7.00/мес за 1 ГБ. Цифра за IP относится к большому пакету — проверять в конфигураторе.
- **proxy-store.com/ru** — «Купить серверные от 23,2 ₽», резидентские от 65 ₽ (325 ₽/ГБ). «От» = самое дешёвое гео: страну проверять в карточке.
- **proxy6.net** — снято рендером JS-таблицы (`₽` за 1 IP): IPv4 выделенный 28 ₽/неделя, 56 ₽/2 недели, 120 ₽/мес (от 100 шт — 99 ₽/мес); IPv4 SHARED 7,7 ₽/неделя, 33 ₽/мес (от 100 шт — 30 ₽); IPv6 20,66 ₽/мес (от 500 шт — 6,72 ₽); MTproto 90 ₽/мес. Цены одинаковые от количества и срока — считать под свой объём.
- **proxyline.net** — IPv4 Shared ≈0,67 $ за IP (порядка 57 ₽), до 3 пользователей на IP; индивидуальные IPv4 — отдельная таблица на той же странице.
- **proxymania.su** — серверные IP считаются в калькуляторе, со страницы не снимаются: брать из кабинета; резидентские там же — 240 ₽/ГБ (пакеты со скидкой до 144 ₽/ГБ).
- **Разброс рынка РФ для ответа «есть ли дешевле»:** минимум, который удалось найти в открытой продаже, — ~20 ₽/мес за IP (IPv6 proxy6) и ~30-33 ₽/мес за shared-IPv4; дешевле — либо публичные списки, либо перепроданный shared, для API-доступа негодные.

Страницы, которые на момент проверки не отдавали контент: `proxys.io` (нет ответа), `best-proxies.ru` (503), `proxy5.net` (403, WAF).

## Дешёвый DIY-вариант вместо покупки

RU-VPS + 3proxy/Dante = прокси под полным контролем, порядка 139 ₽/мес по младшему тарифу (ruVDS «Старт» и аналоги — цифра со страницы провайдера, калькулятор не проверялся), но один IP на сервер. Оправдано, когда нужно 1–5 предсказуемых IP под свои задачи; для ротации — пул (см. `scraping-proxy-pool.md`).

## Что уточнять в тарифе до оплаты

Выделенные IP (не shared) · страна и город выхода (у большинства — только страна) · полоса и лимит соединений на IP · SOCKS5 (нужен для не-HTTP протоколов) · лимит трафика или «unmetered» · стоимость и условия продления ротации адресов · политика замены при бане.

## Алгоритм проверки перед рекомендацией

1. Список прямых сайтов провайдеров (не агрегаторов) через `web-tools search`.
2. Живость пачкой: `curl -s -o /dev/null -w "%{http_code}"` по всем кандидатам.
3. Цены — regex-ом по тексту страницы (`₽`, `руб`, `$`, «за адрес/IP»).
4. Для снятой цены сразу фиксировать: страна, объём, срок.
5. После покупки — `curl -x socks5://user:pass@host:port https://2ip.ru/` (страна/AS/IP), затем тест целевого сайта.
6. Все однотипные пробы гнать одним прогоном (python + `ThreadPoolExecutor` + `subprocess`): живость пачки, цены, TCP-тесты — за один вызов. Короткий скрипт писать файлом и запускать `python3 script.py`, а не длинным heredoc — heredoc уходит на approve-подтверждение и сессия встаёт в ожидании.

## Гео-блок: сначала докажи, что он есть

«Нужны прокси» начинается не с провайдеров, а с проверки, что цель действительно режет зарубежные адреса. Проверка с того сервера, где будет работать клиент:

```bash
dig +short <host>                                                        # резолвится ли вообще
timeout 8 bash -c '</dev/tcp/<host>/443' && echo OPEN || echo BLOCKED    # TCP, а не HTTP
curl -s -o /dev/null -w "http=%{http_code} t=%{time_total}s" --max-time 12 https://<host>/
```

Ключ — контрольные сайты в том же прогоне. Если `yandex.ru` / `mail.ru` / `api.telegram.org` отвечают 302, а цель висит до таймаута (`http=000 t=20s`), режет именно цель. VK и MAX делают это дропом пакетов на уровне IP — не 403 и не капча, поэтому тут спасает только другой IP выхода; смена UA/cookie/заголовков бесполезна. `403` — уже другая история (WAF/антибот), там нужен ISP/резидентский, см. таблицу типов IP выше.

Типичная ошибка — рекомендовать прокси, не проверив это: если цель с текущего сервера отвечает нормально, проблема в чём-то другом, и прокси её не решит.

## Доступ к РФ-API из-за границы (кейс: MAX)

- `max.ru`, `platform-api2.max.ru` и `vk.com` с сервера в Нидерландах (AS50053 VDSka) — глухой TCP-таймаут; Яндекс, mail.ru, `api.telegram.org` при этом работают.
- Прокси вешать только на вызовы к РФ-API: клиент к MAX идёт через прокси, а Telegram Bot API оставлять напрямую — иначе зря гоняется трафик и появляется лишняя точка отказа.
- Для HTTPS-вызовов достаточно HTTP-прокси (CONNECT) или SOCKS5; SOCKS5 обязателен только для не-HTTP протоколов. Один РФ-IP закрывает всего бота — лимиты у платформы на токен, а не на IP.
- MAX Bot API: база — `platform-api2.max.ru` (миграция с `platform-api.max.ru`); токен идёт в заголовке `Authorization` **без** префикса `Bearer` (с ним — 401 «No access token»); подписка на вебхук слетает после 8 часов без успешного ответа эндпоинта, поэтому для простого бота надёжнее поллинг `GET /updates`.
- Критерий приёмки купленного прокси под API: `curl -x http://user:pass@host:port -s -o /dev/null -w "%{http_code}" https://platform-api2.max.ru/me` → **401** значит доступ есть (дело в токене), таймаут значит IP не подходит. Проходит ли дешёвый датацентр-РФ-IP и не фильтрует ли платформа по ASN — проверяется только покупкой; не выдавать это за факт.
