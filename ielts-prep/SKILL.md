# IELTS Preparation (v2)

Система подготовки к IELTS через **сюжетные книги** (жанровые кампании). Каждая книга — расследование, путешествие или приключение, где IELTS задания вплетены в сюжет.

Не заменяет English Lessons, а дополняет их.

## Архитектура

**Vault:** `~/hermes-vault` (github.com/ogodevonline/hermes-vault)

**Структура в Obsidian:**
```
IELTS/
├── state.yaml                              ← фаза, текущая книга, estimated bands, error bank
├── Book-NNN-slug/
│   ├── book.yaml                           ← персонажи, сеттинг, сюжетная база
│   ├── episode-001/
│   │   ├── reading.md                      ← текст + вопросы
│   │   ├── vocabulary.md                   ← слова из текста
│   │   ├── grammar.md                      ← конструкция из текста
│   │   ├── writing.md                      ← эссе + feedback
│   │   └── speaking.md                     ← вопросы + ответы + фидбек
│   ├── episode-002/ ...
│   └── ...
└── ...
```

### state.yaml

phase: foundation                    # foundation / building / pre-exam

  reading: 5.0

## Генерация урока

**Только по запросу пользователя** — как `/english`. Ничего не генерируется заранее.

**prepare** → LLM → **save**

1. `prepare` читает: book.yaml (персонажи, сеттинг, summary) + последний episode summary + error bank + estimated bands
2. LLM генерирует целостный эпизод на основе этого контекста
3. `save` сохраняет в Obsidian + git commit

### Формат эпизода (целостный, одно перетекает в другое)

Все секции завязаны на **один текст**, одну тему:

| Шаг | Что | Откуда |
|-----|-----|--------|
| 🎬 Context | 1-2 предложения: что произошло в сюжете, почему читаем этот текст | Сюжет книги |
| 📖 **Reading** | 150-400 слов (зависит от фазы) + вопросы (T/F/NG, Matching, MCQ) | Сюжет + тема |
| 📝 **Vocab** | 5-7 слов из текста с переводом + пример из текста + коллокации | Из reading |
| 🏗️ **Grammar** | Конструкция из текста: структура, примеры, мини-упражнение | Из reading |
| ✍️ **Writing** | Задание по теме, с requirement: "используй 3 слова из Vocab + 1 Grammar" | Закрепление всего |
| 🎤 **Speaking** | 2 вопроса Part 1/3 по теме (опционально, если не устал) | Завершение |

### Контент для prepare (компактный, ~200 токенов)

- book.yaml: персонажи, сеттинг, summary, plot_threads
- Последний episode writing.md: первые 2 строки как саммари
- Последние 8 слов из vocabulary (чтобы не повторяться)
- Estimated bands + последние 5 ошибок

Никаких полных файлов прошлых сессий. Только саммари.

## Фазы сложности

Фаза растёт/снижается **автоматически**: мало ошибок → фаза вверх, много → фаза вниз. Ручные команды harder/easier форсируют.

| Фаза | Когда | Reading | Writing | Glossary |
|------|-------|---------|---------|----------|
| **Foundation** | A2 | 150-200 слов, простые вопросы | 3-5 предложений с опорами | Да, перед текстом |
| **Building** | A2→B1 | 200-300 слов, сложнее вопросы | Абзац 50-80 слов | Иногда |
| **Pre-Exam** | B1→B2 | 300-400 слов, реальный IELTS стиль | Полноценное эссе 150-200 слов | Нет |

## Команды

| Команда | Действие |
|---------|----------|
| `/ielts` | Меню / начать следующий эпизод |

## CLI скрипт

**Путь:** `~/.hermes/skills/ielts-prep/scripts/ielts_prep.py`

### new-book — создать книгу
```bash
python3 ielts_prep.py new-book \
  --title "Название" \
  --genre "investigation|travel|..." \
  --phase "foundation" \
  --setting "Сеттинг" \
  --characters "YAML список персонажей"
```

### prepare — контекст для генерации
```bash
python3 ielts_prep.py prepare
# → JSON с персонажами, сеттингом, последним эпизодом, ошибками
```

### save — сохранить эпизод
```bash
python3 ielts_prep.py save \
  --reading "..." \
  --vocab "..." \
  --grammar "..." \
  --writing "..." \
  --summary "Сюжетное саммари для book.yaml" \
  --bands '{"reading": 5.5, "writing": 5.0}' \
  --phase "building"  # опционально
```

Аргументы могут быть строками или путями к файлам (начинаются с `/`).

### status — текущий статус
```bash
python3 ielts_prep.py status
```

### error-add / error-list — управление ошибками
```bash
python3 ielts_prep.py error-add --type grammar --description "Описание"
python3 ielts_prep.py error-list
```

## Проведение урока (ЖЁСТКИЙ ФОРМАТ)

**НИКОГДА не скидывать весь урок целиком.** Только шаг за шагом, с ожиданием ответа пользователя.

### Последовательность:

**Шаг 1** → Отправить: 🎬 Context + 📖 Reading text + 🧩 Questions
Ждать ответ пользователя на вопросы.

**Шаг 2** → Проверить ответы:
- Всё верно → похвалить 👍
- Ошибки → объяснить, добавить в error bank через `error-add`
- Если нужно → дать подсказку, спросить хочет ли попробовать ещё раз

**Шаг 3** → Отправить: 📝 Vocabulary (слова из текста)
Можно спросить "все слова понятны?".

**Шаг 4** → Отправить: 🏗️ Grammar + мини-упражнение
Ждать ответ на упражнение. Проверить.

**Шаг 5** → Отправить: ✍️ Writing task
Ждать writing. Проверить по критериям:
- Использованы ли требуемые слова/грамматика
- Основные ошибки (2-3 самые важные, не всё подряд)
- Добавить ошибки в error bank

**Шаг 6** → Отправить: 🎤 Speaking

Speaking вопросы задавать **по одному**, не батчить. 
- После ответа на вопрос 1 → дать фидбек → спросить вопрос 2
- Пользователь может отвечать **голосом или текстом** — и то и то ок
- **НЕ отправлять голосовые сообщения обратно** — фидбек только текстом
- Если пользователь прислал голосовуху — расшифровать, разобрать ошибки, ответить текстом

**Шаг 7** → Выполнить `save`:
- Сохранить все файлы эпизода: reading.md, vocabulary.md, grammar.md, writing.md, **speaking.md**
- Speaking.md создавать отдельно (не через save — write_file напрямую), так как save не умеет speaking.md
- Обновить estimated bands (если пользователь хорошо справился — повысить, если много ошибок — оставить/понизить)
- Обновить summary для book.yaml
- Упомянуть что сохранено в Obsidian

### Правила фидбека:
- Не исправлять каждую букву — 2-3 самые важные ошибки
- Сначала похвалить, потом исправить
- Если ошибка из error bank повторилась — сказать "помнишь, мы уже это разбирали?"
- На A2 Foundation фазе: прощать мелкие ошибки (артикли), фокус на главном (порядок слов, will+V1, was/were)

## ⚠️ Pitfalls

1. **Не перегружать** — IELTS prep не заменяет English Lessons. 1 эпизод в день максимум.
2. **В начале эпизода — glossary** для Foundation фазы. Сложные слова перед текстом, а не после.
3. **Сюжет важнее IELTS** — если пользователю интересно что дальше, он сам захочет читать и писать.
4. **save делает git commit автоматически** — проверять `git log --oneline -1` после save.
5. **Error bank живёт в state.yaml** — не создавать отдельные файлы для ошибок, только записи в yaml.
6. **Не больше 2 книг активными** — параллельное ведение возможно, но больше запутает.
7. **НЕ скидывать всё сразу** — шаг за шагом, каждый шаг с ожиданием ответа.
8. **Speaking вопросы по одному** — не батчить 2 вопроса в одном сообщении.
9. **Не слать голосовые обратно** — фидбек на голосовухи только текстом.
10. **Тестовые данные чистить** — если создавал тестовый эпизод при настройке, удалить до того как пользователь увидит. Иначе сбивает сюжет.
11. **save делает git push через post-commit хук** — проверить `git log --oneline -1` + не помешает проверить что push прошёл. Если нет — сделать `git push` вручную.
12. **После save проверить что все файлы создались** — `ls episode-NNN/` должен показывать reading, vocabulary, grammar, writing, speaking.
