## Структура описания

```
Уй сатылады N комта асхана болек M жататын болме Бир зал бахасы X млн келисимли
→ Дом N комнат, кухня отдельно, M спален, зала, цена X млн, торг

Манзил Нокис каласы Район Адрес
→ Адрес: г. Нукус, район, адрес

Газ ток суў проблема жок
→ Газ, свет, вода — проблем нет
```
