# Курсы валют в Узбекистане — поиск и сравнение

## Источники данных

| Сайт | Тип | Пригодность | Примечание |
|------|-----|-------------|------------|
| pulbek.uz/currencies/nukus | Агрегатор по городам | ✅ Лучший | JS-рендер, нужен browser + browser_console |
| bank.uz/currency | Агрегатор по Узбекистану | ✅ Хорошо | Показывает топ курсов, НО без фильтра по городам |
| bankchart.uz/spravochniki/kursy_valyut_city/{id} | Агрегатор по городам | ✅ Хорошо | Средние курсы по городу, список банков |
| nukus.kreditlar.uz/currency/usd | Агрегатор по городам | ⚠️ Часто пусто | Динамическая таблица, часто показывает "Нет данных" |
| cbu.uz (ЦБРУ) | Официальный курс | ℹ️ Только ориентир | Курс ЦБ — не курс обмена наличных |
| vbr.uz | Агрегатор | ⚠️ Не проверялся | — |
| goldenpages.uz | Справочник | ❌ Только адреса | Не содержит курсов |

## Алгоритм для поиска лучшего курса USD→UZS в городе Узбекистана

### Шаг 1. Поиск агрегаторов

```bash
~/.cargo/bin/web-tools search "курс доллара Нукус банки сегодня" --source yandex --domain uz
```

Ключевые слова: `курс доллара {город} сегодня`, `курсы валют {город}`, `{город} valyuta kurslari`

### Шаг 2. Извлечение средних курсов (bankchart.uz)

`bankchart.uz/spravochniki/kursy_valyut_city/{id}` — показывает среднюю покупку/продажу USD по городу.
ID города для Нукуса: `117198`.

```bash
~/.cargo/bin/web-tools extract "https://bankchart.uz/spravochniki/kursy_valyut_city/117198"
```

Выдаёт:
- Средний курс покупки USD (банк покупает = твой курс при USD→UZS)
- Средний курс продажи USD (банк продаёт = твой курс при UZS→USD)
- Список банков с отделениями в городе

### Шаг 3. Детальные курсы по банкам (pulbek.uz — JS-сайт)

`pulbek.uz/currencies/{city}` — JS-рендер, `web-tools extract` не работает.

**Процедура:**

1. `browser_navigate("https://pulbek.uz/currencies/nukus")` — открыть страницу города
2. `browser_console` с JS-запросом для извлечения таблицы курсов:

```javascript
// Извлекает все строки банков с курсами USD/EUR/RUB
// Структура: Название банка → Купить USD → Сдать USD → Купить EUR → Сдать EUR → Купить RUB → Сдать RUB
let result = [];
document.querySelectorAll('[class*="bank"], [class*="currency"], [class*="rate"]').forEach(el => {
  if(el.querySelector('a') || el.innerText.trim().match(/^\d/))
    result.push(el.innerText.trim());
});
result.join('\n---\n');
```

ИЛИ более широкий захват (если первый не сработал):

```javascript
document.body.innerText
```

### Шаг 4. Альтернатива: bank.uz (топ курсов без фильтра по городу)

`bank.uz/currency` — показывает **лучшие курсы по Узбекистану в целом** (не по конкретному городу).

Страница в браузере показывает:
- USD Покупка (банк покупает доллары): Universal bank, BRB, Openbank...
- USD Продажа (банк продаёт доллары): Anorbank, Kapitalbank, Turon bank...

⚠️ Это общеузбекские курсы. В регионах курс может отличаться на 20-50 сум.

### Шаг 4.5. Per-bank официальные курсы (bank.uz/bank/{bank-name})

`bank.uz/currency/bank/{bank-name}` — полная таблица курсов конкретного банка. Например: `bank.uz/currency/bank/kapitalbank`.

**Что даёт:** Покупка / Продажа / Время обновления (например, «24.07.2026 15:02») для USD, EUR, RUB, GBP, CHF, KZT, JPY.
**Рендер:** Статический HTML — browser_snapshot видит все строки таблицы.
**Использовать когда:** Kapitalbank или другой банк не отображается в pulbek.uz, или нужны другие валюты помимо USD/EUR/RUB.
**Недостаток:** Общебанковские курсы, не привязанные к конкретному городу.

### Шаг 5. Сборка таблицы сравнения

Формат вывода для пользователя:

**USD → UZS (покупка USD банком — чем выше, тем выгоднее):**

| Банк | Продают USD | Покупают USD |
|------|:-----------:|:------------:|
| Poytaxt Bank 🥇 | 12 160 | **12 010** |
| Invest Finance 🥈 | 12 150 | **12 000** |
| ANOR BANK 🥉 | 12 110 | **12 000** |

- Если пользователь меняет **USD → UZS** — ему нужен столбец **«Покупают USD»** (банк покупает его доллары). Чем выше — тем лучше.
- Если пользователь меняет **UZS → USD** — ему нужен столбец **«Продают USD»** (банк продаёт ему доллары). Чем ниже — тем лучше.

### Ключевые понятия (путаница в терминах)

Пользователь говорит «купить сумы за доллары». На агрегаторах:
- **«Купить» / «Продают USD»** = банк **продаёт** тебе доллары (ты отдаёшь сумы)
- **«Сдать» / «Покупают USD»** = банк **покупает** твои доллары (ты получаешь сумы) ← вот это нужно

### Pitfalls

1. **pulbek.uz — данные не в snapshot.** Используй `browser_console` с JS, а не `browser_snapshot`.
2. **nukus.kreditlar.uz — часто пустой.** Если видишь "Нет данных о курсах валют" — не трать время, переходи к другому источнику.
3. **bank.uz — только топ, без городов.** Показывает 3 лучших курса по стране, не по конкретному городу.
4. **Курсы могут устареть на 25+ мин.** Агрегаторы обновляются не в реальном времени. Всегда советуй уточнять в отделении.
5. **Разница между банками в одном городе: 20-50 сум.** Не гнаться за идеалом — разница на $100 = 2,000-5,000 сум (~$0.15-0.40).
6. **web-tools extract для bankchart.uz — работает, НО детальная страница `/usd` — 404.** Используй основной URL города без `/usd`.
7. **Курсы меняются в течение дня.** Утром курс покупки USD может быть выше, к вечеру — ниже на 20-50 сум. Всегда показывать время обновления из источника (на bank.uz есть колонка «Время обновления», на pulbek.uz — дата в заголовке).
8. **Kapitalbank.uz → HTTP 403 (WAF).** Не пытайся открыть официальный сайт Kapitalbank — WAF блокирует. Используй bank.uz/currency/bank/kapitalbank как единственный доступный источник их курсов.
