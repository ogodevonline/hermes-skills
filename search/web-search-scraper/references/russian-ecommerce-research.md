# Russian E-commerce Research (товары по размерам/спецификациям)

## Проблема

Поиск товаров с конкретными техническими характеристиками (размеры, вес, мощность) через Яндекс/Google по русскоязычным магазинам — не тривиален. Крупные магазины используют JS-рендеринг каталогов, и web-tools не может извлечь список товаров со страниц категорий.

Результат: ссылки на страницы характеристик с разных сайтов.

### 3. Стратегия поиска товаров по точным габаритам

```
1. Попробовать поиск по точным размерам:
   "холодильник 585х575 мм"
   "ширина 58.5 глубина 57.5 холодильник"
   → почти всегда категории, не модели

2. Затем — по брендам с близкими размерами:
   "site:vasko.ru холодильник ширина 58"
   "Liebherr ширина 58 глубина 57 размеры"

3. Найти хотя бы одну модель → извлечь её характеристики →
   сравнивать через поиск модели + "размеры ширина глубина"
```

## Алгоритм для research товара с точными размерами

```
1. Спросить у пользователя высоту, бюджет, нужные функции
   (уточняющие вопросы экономят 10+ поисков)

2. Определить, какие бренды делают такой размер
   - Ширина 55-57 см (очень узкие): NORD, Nordfrost
   - Ширина 58-58.7 см: Atlant, Gorenje, Liebherr, Sharp, DEXP, Bosch (редко)
   - Ширина 54-55 см (классика узких): Pozis, Biryusa, Maunfeld, DEXP
   - Глубина <59 см: неглубокие модели, крайне редки в бюджете до 40 тыс. руб.
     Большинство бюджетных моделей имеют глубину 60-65 см
   - Невысокие (до 180 см): Pozis, Nord, Biryusa, DEXP, Nordfrost (высота ~150-166 см)

3. Поиск конкретных моделей:
   ~/.cargo/bin/web-tools search "<бренд> <модель> размеры ширина глубина" --source yandex --count 10 --lr 213

4. Извлечение характеристик:
   ~/.cargo/bin/web-tools extract "https://vasko.ru/..." --parallel 2 --timeout 15
   ~/.cargo/bin/web-tools extract "https://buybt.ru/..." --parallel 2 --timeout 15

5. Если страница пустая (JS) — попробовать другой сайт из списка рабочих
```

## Запросы для поиска холодильников по размерам

Самые эффективные запросы (работают для холодильников, стиральных машин, посудомоек):

```
"холодильник <ширина> см ширина <глубина> глубина"
"холодильник <ширина>x<глубина> см"
"холодильник ширина <ширина> глубина <глубина> невысокий"
"холодильник неглубокий ширина <ширина>"
"холодильник <бренд> ширина <ширина> глубина <глубина>"
```

## ⚠️ Presentation rules

### Формат вывода сравнения моделей

Пользователь ждёт **явные названия колонок** (Ширина, Глубина, Высота), а не сокращения вроде `Ш×Г×В`. Таблица должна читаться сразу, без расшифровки.

**Правильно:**
```
| Модель | Ширина | Глубина | Высота | No Frost | Цена |
|--------|--------|---------|--------|----------|------|
| NORD NRB 121 W | 57.4 см | 62.5 см | 150 см | Нет | ~27 тыс |
```

**Неправильно (вызывает путаницу):**
```
| Модель | Ш×Г×В (см) | No Frost | Цена |
```

После таблицы — краткая сводка: какие колонки совпадают с требованиями пользователя, какие нет, и какие есть варианты решения.

### Размер в коробке (для лифта)

Когда пользователь спрашивает про размер в упаковке — добавляй ~5-8 см к каждому габариту. Пример: NORD NRB 121 W (150×57.4×62.5 см без коробки → ~157×64×69 см в коробке). Если размеры упаковки не удалось найти на vasko (там иногда есть «Габариты в упаковке»), округли вверх.

### Yandex Market короткие ссылки

Ссылки вида `market.yandex.ru/cc/<hash>` — сокращённые, ведут на капчу. Не пытайся их распарсить. Проси пользователя открыть самому и сказать что там.

## 🚚 Организация доставки + забор старого

При поиске крупной техники (холодильники, стиралки) пользователю часто нужно не только купить, но и избавиться от старой.

**Где есть забор старого:**
- **Wildberries** — есть опция «Утилизация старой техники» при заказе (~1 000 ₽)
- **М.Видео** — услуга утилизации, ~1 000 ₽
- **DNS** — при доставке
- **OZON** — НЕТ встроенной опции забора старого холодильника (на момент 06.2026). Можно через отдельную услугу «Вывоз бытовой техники» или нанять частника

**Отдельный вызов для старого:**
- YouDo (youdo.com) — 1 500–2 000 ₽ частники с газелью
- Экотакси «Убери» (uberi.pro) — от 2 300 ₽, вывоз + утилизация
- Авито → дать объявление «Отдам даром» — 0 ₽, если старый рабочий

## 🔄 Перенавешивание дверей

При поиске по картинкам/фото все модели обычно показаны с **правым** открытием двери. Не факт, что так и должно быть.

**Что проверять перед тем, как сказать «нет» из-за открытия:**
1. В характеристиках найти «Перенавешиваемые двери: Да»
2. Если параметр есть — пользователь сам перевешивает за 15 минут отвёрткой

**Типичные запросы:**
```
"<модель> перенавешивание дверей"
"<модель> перевесить дверь влево"
```
Если в найденной карточке товара (vasko, buybt) написано «Перенавешиваемые двери: Есть» — открытие не проблема.

## Pitfalls

1. **Числа в названии моделей (585, 575) — НЕ размеры.** Чаще это объём в литрах или номер серии.
2. **Категории магазинов — тупик.** Если в выдаче только ссылки на категории (catalog/recipe/..., /filter/..., /tags/...) — не пытайся их парсить, смени запрос.
3. **Ограничение по количеству вызовов.** Если после 15-20 поисковых запросов нет конкретных моделей — признай, что размер нестандартный, и предложи пользователю сузить критерии (увеличить допуск, сменить тип техники).
4. **Бюджетные бренды.** Pozis, Biryusa, Nord, DEXP, Atlant чаще имеют нестандартные/компактные корпуса. Премиум-бренды (Miele, Liebherr, Gaggenau) — стандартные размеры.
5. **Глубина <60 см в бюджете до 40 тыс — редкость.** Почти все бюджетные двухкамерные холодильники имеют глубину 60-65 см. Если пользователю нужно <59 см по глубине + до 40 тыс — скорее всего не найдётся, нужно расширять бюджет или допуск.
6. **NORD/Nordfrost — ширина 57–57.4 см.** Узкие модели этих брендов (NRB 121 W, NRB 122 W) имеют ширину 57-57.4 см, что уже стандартных 58-60 см. Это промежуточный размер между узкими (54-55) и стандартными (59.5-60).
7. **Eldorado.ru — HTTP 503.** Не парсится, возвращает 503 Service Unavailable.
8. **wildberries.ru — HTTP 498.** Кастомный код блокировки, не парсится.
