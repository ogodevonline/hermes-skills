# Параметры XMLStock (yandexlive/json/)

Эндпоинт: `https://xmlstock.com/yandexlive/json/`

## Работающие параметры

| Параметр | Пример | Описание |
|----------|--------|----------|
| `user` | `14157` | ID пользователя (обяз.) |
| `key` | `...` | API-ключ (обяз.) |
| `query` | `музеи москвы` | Поисковый запрос (обяз.) |
| `page` | `0` | Номер страницы (с 0) |
| `lr` | `213` | Регион: 213=Москва, 11116=Ташкент |
| `sortby` | `tm` или `rlv` | Сортировка: по релевантности или времени |
| `domain` | `ru`, `uz`, `kz`, `by`, `com` | Доменная зона Яндекса |

## НЕ работающие параметры

Эти параметры есть в документации `yandex/xml/` но НЕ поддерживаются `yandexlive/json/`:

- `groupby` — ошибка: "Для ЯндексLive доступен сбор только ТОП-10"
- `maxpassages` — не влияет на ответ
- `filter` — не влияет
- `l10n` — не влияет
- `device` — не влияет
- `noreask` — не влияет

## Поля ответа

Каждый элемент в `results` содержит:

| Поле | Тип | Описание |
|------|-----|----------|
| `url` | string | Полный URL |
| `title` | string | Заголовок страницы |
| `passage` | string | Сниппет/описание (~150-200 символов) |
| `contenttype` | string | `organic`, `news` и т.д. |
| `breadcrumbs` | string/nil | Хлебные крошки |
| `cachelink` | string | Ссылка на веб-кэш Яндекса |

## Полезные lr-коды

| Код | Регион |
|-----|--------|
| 213 | Москва |
| 1 | Санкт-Петербург |
| 11116 | Ташкент |
| 11117 | Нукус |
| 10927 | Ташкентская область |
| 11118 | Самарканд |
| 149 | Узбекистан (вся страна) |
