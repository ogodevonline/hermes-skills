# Research Strategy — какой инструмент когда использовать

## Бесплатные поисковые backend'ы в Hermes

Встроенный `web_search`/`web_extract` использует backend из `config.yaml` (`web.backend`). Варианты:

| Backend | Бесплатный план | Особенности |
|---------|----------------|-------------|
| **DuckDuckGo (ddgs)** | Неограниченно | Установлен, быстрый поиск, без ключа |
| **Tavily** | 1000 запросов/мес | Built-in, поиск+извлечение+crawl, быстрый |
| **Brave Search** | 2000 запросов/мес | Через MCP, только поиск |
| **Firecrawl** | Бесплатный tier | Built-in, стоит по умолчанию, но без ключа не работает |

**Текущая конфигурация:** DuckDuckGo (ddgs) — fast, free, без ключа.

## Быстрый факт (дата, определение, столица и т.п.)
→ **Встроенный `web_search`** (быстрее всего, 1-2 сек, через ddgs)

## Русскоязычный поиск с контентом
→ **`web-tools CLI`** (`~/.cargo/bin/web-tools search`) — приоритетный инструмент. Rust бинарник, быстрее Python.
  - Поиск: `~/.cargo/bin/web-tools search "запрос" --count 30 --source yandex`
  - Экстракт: `~/.cargo/bin/web-tools extract url1 url2 --parallel 10`
  - Полная справка: `references/web-tools-cli.md`
- Отзывы, рестораны, места, события в РФ/Узбекистане/Казахстане
- Новости на русском
- Анализ рынка с региональной привязкой
→ **`web-search-scraper`** (Python search.py) — fallback если бинарник не найден

## Извлечение контента из 1-5 конкретных URL
→ **`~/.hermes/scripts/web_extract.py`** — параллельный асинхронный сбор контента
  - **Движки:** trafilatura (быстро, качественно) → httpx+BeautifulSoup (fallback)
  - **Ретраи:** 2 попытки с exponential backoff, таймаут 15с на попытку
  - **Параллельно:** `asyncio.gather()` — несколько URL одновременно
  - **Использование:** `python3 ~/.hermes/scripts/web_extract.py <url1> <url2> [--chars N]`
  - **`--chars N`:** ограничить вывод (работает и как `--chars=N`, и как `--chars N`)
  - **Результат:** markdown с заголовками URL и содержимым
  - **Когда использовать:** у вас есть конкретные URL (статьи, документация, объявления) и нужно быстро получить их содержание. Не для массового сбора — для этого `search.py --preview`.

## Глубокий анализ одного сайта (SPA, классифайды)
→ **`crawl4ai`** — для SPA (React/Vue), классифайдов (OLX), Telegram каналов

## Академические статьи/research papers
→ **`arxiv`** (поиск по arXiv.org)

## Мониторинг обновлений (RSS/блоги)
→ **`blogwatcher`** (сканирование RSS/Atom лент)

## Авиабилеты / цены на перелёты
→ **Aviasales Data API (Travelpayouts)** — БЕСПЛАТНО, точные цены, ссылки на покупку
- Регистрация на travelpayouts.com, API-токен в профиле
- Эндпоинт: `/aviasales/v3/prices_for_dates` — цены на дату, авиакомпания, ссылка
- Эндпоинт: `/v2/prices/month-matrix` — календарь цен на месяц
- Falls back к **`web-search-scraper`** (XMLStock) если токена нет

## Приоритет (общий порядок)
`web-tools` CLI (Rust, быстрее всех) → `web_search` (ddgs) для быстрой разведки → `web-search-scraper` (Python) для глубины → `web_extract.py` для контента конкретных URL → `crawl4ai` если нужен один конкретный сложный сайт

## Особый случай: юридические/регуляторные запросы (законы, визы, регистрация, налоги)

**Приоритет источников** (исправлено 17.07.2026):

1. **Текст закона/договора** — ищи на официальных правовых порталах (lex.uz, pravo.gov.ru, mid.ru, docs.cntd.ru). Цитируй конкретную статью и пункт.
2. **Официальные разъяснения госорганов** — МИД, МВД, миграционные службы, посольства.
3. **Проверенные юридические/аналитические публикации** — сайты с указанием даты и ссылкой на закон.
4. **Форумы/блоги** — ТОЛЬКО если первичные источники недоступны. Всегда проверяй и перепроверяй.

**Всегда проверяй** наличие двусторонних соглашений — они часто отменяют общие правила (как соглашение РФ-РУз от 2021 даёт россиянам 15 дней вместо общих 3).
