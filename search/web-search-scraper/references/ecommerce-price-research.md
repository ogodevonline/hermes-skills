# Price Research for CIS/Uzbek e-commerce

## Проблема

Uzbek retail sites (Texnomart.uz, Uzum.uz, Mediapark.uz, OLX.uz) are JS-rendered SPA.
`web-tools extract` returns **empty content** for their product listing pages — no prices.
Browser tool is needed for actual price data.

## Алгоритм

### 1. Discovery — web-tools search

```
~/.cargo/bin/web-tools search -c 10 "стиральная машина цена сум Узбекистан 2026"
```

Из результатов выбери URL конкретного магазина (texnomart.uz, mediapark.uz, uzum.uz).

### 2. Browser — навигация на страницу категории

Browser navigate to the Texnomart/Uzum category page.

**Texnomart:** после загрузки появляется модалка региона. Нажми "Да" (ref из snapshot).
Затем используй browser_console с JS-запросом для извлечения товаров + цен.

### 3. Browser — извлечение данных

```javascript
// Собрать карточки товаров с ценами
JSON.stringify([...document.querySelectorAll('[class*="card"], [class*="product"]')].slice(0,30).map(el => el.textContent.trim().replace(/\s+/g, ' ')).filter(t => t.includes('сум')).slice(0,15))
```

Texnomart возвращает полные карточки: название модели, характеристики, цену сум, рассрочку — всё в одном textContent.

### 4. Перевод сум → USD

Курс на июль 2026: **~12 000 сум = $1**.
Для точного курса на сегодня:
```
~/.cargo/bin/web-tools search -c 3 "курс доллара к суму $(TZ=Europe/Moscow date +'%d %B %Y') Узбекистан"
```

## Food ingredients / Small business supplies (попкорн, кондитерка)

Поиск ингредиентов и упаковки для мелкого производства (50-100 единиц продукции).

### Алгоритм

1. **Разведка — web-tools search:**
   - `~/.cargo/bin/web-tools search "кукуруза попкорн зерно цена Узбекистан кг" --source yandex`
   - `~/.cargo/bin/web-tools search "глазурь шоколадная кондитерская купить Нукус" --source yandex`
   - `~/.cargo/bin/web-tools search "ПЭТ банка 500 мл пластик оптом Узбекистан" --source yandex`
   - Ищи на Flagma.uz (B2B), OLX.uz (свежие объявления, живут ~неделю), Uzum.uz (поисковые сниппеты, капча), Wildberries.uz (browser, JS SPA)

2. **Типографии в Нукусе (наклейки/этикетки):**
   - Известные: Нукусский полиграфкомбинат, Darhan Print, Golden Print
   - Онлайн-типографии Ташкента с доставкой: nakleyki.uz, copy.uz

3. **Trapeza.uz — B2B поставщик для стритфуда/попкорна (работает, нет капчи):**
   - `https://www.trapeza.uz/catalog/kinoteatr_fanfud_stritfud/popkorn/` — 569 товаров: зерно, глазурь, масло, аппараты, упаковка
   - Категория «Упаковка для попкорна» — ищи через checkbox в фильтре «Упаковка для попкорна»
   - Цены видны в snapshot (например: "3273641,85 сум/шт" — аппарат сахарной ваты)
   - Browser работает (нет капчи), доставка по Узбекистану, контакт +998 99 9724307
   - URL-схема: `/catalog/kinoteatr_fanfud_stritfud/popkorn/upakovka_standartnaya/`

4. **Сравнение рынок vs онлайн:**
   - Рынок (базар) в Нукусе часто в 2-5 раз дешевле маркетплейсов
   - Исключение: простые товары без бренда (наклейки) — на Uzum/WB могут быть сравнимы

### Пример: попкорн-бизнес на 50 баночек (июль 2026)

| Позиция | Кол-во | Рынок Нукуса | Uzum Market |
|---------|--------|-------------|-------------|
| Кукуруза для попкорна | 2 кг | 60 000 сум (30 000/кг) | ~74 000-85 000 (вес неясен) |
| Глазурь Карат Каверлюкс молочная | 1 кг | 100 000 сум (100 000/кг) | ~100 000+ (оценка, капча) |

| ПЭТ баночки 500 мл | 50 шт | 50 000-100 000 сум (1 000-2 000/шт) | 37 000/шт = 1 850 000 ❌ |
| Соль + сахар + масло | — | ~15 000 сум | — |
| Наклейки круглые (с лого) | 60 шт (3 листа) | 15 000 сум (5 000/лист × 3) | 18 900 сум/60 шт (цветные, без лого) |

**Финальный бюджет:** ~290 000 сум ($23) на старт 50 баночек.
**Розничная цена:** рынок Нукуса продаёт маленькие баночки по 5 000-6 000 сум.
**Стратегия пользователя:** красивая упаковка + премиальная подача → продажа дороже рыночной цены.

**Вывод:** рынок Нукуса дешевле Uzum по всем продуктам. Uzum конкурентоспособен только на наклейках.

### Питфоллы

1. **Цена в сниппете Uzum — может быть за минимальный вес.** В заголовке товара может быть "0.5 кг, 1 кг, 2 кг" с одной ценой. Не угадывай вес.
2. **Не пересчитывай бюджет без уточнения.** Если пользователь написал "30 000 сум" на 2 кг, уточни: это за кг или всего? Не делай предположений.
3. **OLX.uz объявления устаревают за 1-7 дней.** Старые показывают "Объявление больше не доступно". Только свежий поиск даёт работающие ссылки.
4. **Wildberries.uz не показывает цену в snapshot карточки из списка.** Нужно кликнуть в товар или browser_console.

## Home setup: бытовая техника и мебель для дома (Нукус)

Сбор цен на крупную бытовую технику и мебель для обустройства дома. Пользователь покупает для новой квартиры/дома «с нуля».

### Алгоритм

1. **Artel — дефолтный бенчмарк бюджетной техники в Узбекистане.** Узбекский производитель Artel — самый доступный бренд для кондиционеров, холодильников, стиральных машин. Ищи «Artel + категория» для baseline-цены, потом сравнивай с другими брендами.
2. **Источники (по приоритету скорости/доступности):**
   - Uzum.uz поисковые сниппеты — быстрый ориентир «от X сум» (капча, только сниппеты)
   - Texnomart.uz — browser работает, регион-модалка, цены через browser_console JS
   - Idea.uz — альтернатива Texnomart, часто дешевле, URL-фильтр по цене
   - OLX.uz Нукус — для мебели (хонтахта, ковры), объявления живут ~1-7 дней
3. **Формат результата — диапазон (эконом vs комфорт):**
   - Эконом: Artel или бюджетные бренды (Loretto, Premier, Kleo)
   - Комфорт: средний сегмент (Hisense, LG базовая, Samsung)
   - Если точной цены нет — укажи «от X сум» с источником и пометкой «ориентир»

### Доставка в Нукус
- **Texnomart** — доставляет по всему Узбекистану, контакт-центр +99871 209 99 44
- **Uzum** — доставляет (проверять при оформлении)

### Питфоллы по домашней технике

1. **Всегда уточняй у пользователя, если цена выглядит подозрительно.** Если пользователь написал «30 000 сум на 2 кг» — это может быть 30 000 за всё ИЛИ 30 000/кг. Спроси перед расчётом.
2. **Не путай цену за минимальный вес/объём в сниппетах.** Uzum показывает одну цену на товар с вариантами веса. Цена может быть за 0.5 кг, а не за 2 кг.
3. **OLX.uz объявления не работают через browser.** Не трать время на открытие — бери данные из поисковых сниппетов.
4. **Mediapark.uz — Cloudflare.** Не пытайся открыть — сразу используй альтернативы (Texnomart, idea.uz).
5. **Не создавай отдельную Kanban-задачу на сбор цен.** Сбор цен — это быстрая работа с browser + web-tools. Kanban нужен только когда требуется анализ/синтез по собранным данным.

## Pitfalls

1. **Texnomart показывает регион-модалку** — всегда нажимай "Да" (регион уже выбран), иначе каталог не загрузится.
2. **Цены в сум — всегда переводи в USD** для понятности пользователю. Курс проверяй на текущую дату.
3. **OLX.uz не даёт цены через browser console** — там отдельные объявления. Используй поиск с ценами в запросе (`olx.uz ... цена 2000000`).
4. **Не создавай Kanban-задачу для простого сбора цен** — browser + web-tools быстрее и дешевле самому. Kanban researcher нужен только когда нужен анализ/синтез, а не сбор чисел.
5. **Wildberries.uz — browser работает, но как SPA** — клик по article может не сработать для перехода на страницу товара. Используй browser_console для извлечения URL из ссылки, потом browser_navigate на неё.
