# Список и ЛПР

**Читать, когда:** собираешь список бизнесов или ищешь, кто решает.
**Не читать, если:** список уже есть — вернись к [SKILL.md](../SKILL.md).

## 1. Кому продаём (ICP) — 5 минут

Ответить одним абзацем + чек-лист «годится / нет»:
- Кто платит и кто решает (владелец сам? администратор? сеть?). **Продавать сначала туда, где тот, кто решает, и тот, кто отвечает на сообщения, — один человек** (мастер, тренер, маленький салон). Там 1 разговор вместо недель.
- Признак боли, видимый снаружи (много отзывов = много клиентов = много переписки; запись «по телефону/в директ»; нет онлайн-записи).
- Дисквалификаторы: гос. учреждения, сети с головным офисом, закрытые, без контакта.

## 2. Где взять список (бесплатно, без покупки баз)

| Источник | Что даёт | Как |
|---|---|---|
| Яндекс.Карты / Google Maps | название, телефон, адрес, рейтинг, число отзывов, Instagram/Telegram | скрипт `scripts/ymaps.mjs` (Playwright, медленно, с паузами) |
| Реестры юрлиц (UZ: orginfo.uz; RU: rusprofile, egrul.nalog.ru; KZ: kgd.gov.kz) | **директор (ЛПР) и его телефон** | поиск по названию + город |
| 2GIS | то же, что карты, иногда больше телефонов | вручную/браузер |
| Instagram (поиск по городу и нише) | живые бизнесы, директ | вручную |
| Каталоги/агрегаторы ниши | кто уже платит за онлайн-запись (сильный сигнал) | вручную |
| Чаты/каналы предпринимателей города | тёплые входы, посевы | вручную |

Правила: только публичные контакты, свой темп запросов, хранить источник и дату у каждой строки.
Итог шага: CSV `name, phone, instagram, telegram, rating, reviews, address, source, lpr_name, lpr_phone`, отсортированный по числу отзывов.

## 3. Как дойти до ЛПР

По порядку, пока не нашёлся:
1. Реестр юрлиц: «Rahbar»/«Руководитель» + телефон компании (часто личный номер владельца, а не ресепшен).
2. Instagram бизнеса: в шапке/хайлайтах «владелец @…», «founder».
3. Отзывы на картах: кто отвечает от имени бизнеса (часто владелец, с именем).
4. Через ресепшен одним вопросом: «Kim hal qiladi bunday narsalarni — rahbaringizmi? Ismi nima?» / «Кто у вас решает такие вопросы — руководитель? Как его зовут?» И потом писать уже ему по имени.
5. Визит лично / знакомые / поставщики, которые к ним ходят.
