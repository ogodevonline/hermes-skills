# Доступ к гео-заблокированному сервису

Класс задач: «сервис X не работает с моего сервера/бота» и «найди дешёвые прокси под X». Пользователь ведёт ботов из-за рубежа к российским сервисам (MAX/VK, маркетплейсы) — блокировки там на уровне IP, а не капчи.

## When to Use

- Запрос «найди прокси» / «нужны российские прокси» под конкретный сервис или бота.
- Сервис/API не отвечает с текущего хоста: таймаут или «регион не поддерживается».
- Надо оценить, кто из провайдеров реально даст рабочий выход и сколько это стоит по минимальному чеку.

## Что делать по порядку

### 1. Не покупать ничего, пока не доказан слой блокировки

Сначала ответь на вопрос «что именно не пускает» — иначе выберешь не тот класс IP.

```bash
# DNS резолвится? (если нет — вообще не блок, а DNS/домен)
dig +short <host> @8.8.8.8
# TCP/HTTP-слой: timeout = фильтр по IP; 401/403 = приложение живо
curl -s -o /dev/null -w "http=%{http_code} t=%{time_total}s ip=%{remote_ip}" --max-time 20 https://<host>/
```

**Контрольная группа обязательна.** Проверь с того же хоста 2-3 заведомо доступных сайта — иначе свалишь на «гео-блок» сетевую поломку хостинга:

```bash
for u in https://yandex.ru/ https://mail.ru/ https://api.telegram.org/; do
  curl -s -o /dev/null -w "$u -> %{http_code} %{remote_ip}\n" --max-time 12 "$u"
done
```

Интерпретация: соседи отвечают 302, а цель висит 20с с `http=000` и пустым `remote_ip` → дроп пакетов по IP, сервис не пускает этот регион/ASN. Это доказательство, а не догадка.

### 2. Инвентаризация — что у пользователя УЖЕ оплачено

Перед покупкой проверь его текущие ресурсы: у него может быть сервер, MCP или прокси, уже стоящие в нужной стране, и задача решается маршрутом, а не подпиской. Смотри `~/.hermes/config.yaml`, `~/.hermes/.env`, заметку «Сервисы и подписки» в vault, живые ключи провайдеров.

### 3. Класс exit-IP выбирать по антиботу ЦЕЛИ, а не по цене

| Цель | Что проходит | Что бесполезно |
|---|---|---|
| Гео-фильтр РФ (просто не пускает иностранцев) | любой РФ-адрес: датацентр, ISP, мобильный | зарубежный любой ценой |
| Маркетплейсы РФ (Wildberries, Ozon, Avito, CIAN) | ISP-адрес провайдера (Ростелеком/МТС) или мобильный | датацентр любого хостера — блэклисты по ASN |
| Cloudflare-защита | резидентские/мобильные | датацентр (Hetzner/OVH/AWS) |
| Свои API, Telegram-аккаунты, общий парсинг | датацентр | — |

Гео-фильтр проверяет **страну**, антибот маркетплейсов — **тип сети**. Датацентр-IP РФ закрывает первое и не закрывает второе.

### 4. Цены — снимать с живых страниц, а не из обзоров

Прайс-таблицы провайдеров рендерятся JS: `web-tools extract` вернёт HTML без цифр (видны только заголовки колонок). Рецепт рендера и проверенная раскладка цен РФ-рынка — `references/russia-datacenter-proxy-market.md`.

### 5. Проверка перед рекомендацией и после покупки

```bash
# 1) выходной IP и страна — должен быть нужный регион
curl -x http://LOGIN:PASS@HOST:PORT -s --max-time 15 "http://ip-api.com/json/?fields=country,isp,as"
# 2) доступность ЦЕЛИ (не сайта провайдера!)
curl -x http://LOGIN:PASS@HOST:PORT -s -o /dev/null -w "%{http_code}\n" --max-time 20 https://<host>/<health-path>
```

- Ожидаемый код = «сервис пустил, дальше уже токен/логин» (для API без ключа это 401). **Таймаут — прокси задачу не решил**, даже если ip-api показывает нужную страну.
- Пометки в ответе: ✅ проверено живьём / ⚠️ не проверял. Список провайдеров из выдачи без проверки — не ответ, пользователь это ругает.
- Минимальный тест = 1 IP на месяц: сначала проверяем цель, потом продлеваем.

### 6. DIY-вариант, который обычно дешевле готовых прокси

Если нужен один IP под сервис/бота: RU-VPS + `3proxy` (или `gost`) даёт свой HTTP/SOCKS5 с авторизацией и безлимит трафика — платишь за сервер, а не за IP. Один IP закрывает бота целиком (лимиты у API обычно на токен, а не на IP).

## Pitfalls

- **Не путать «провайдер живой» с «прокси рабочий».** 200 на сайте провайдера ничего не говорит о том, что его IP пройдёт в цель.
- **Минимумы съедают дешёвую цену за IP.** Зарубежные сети вида $0.03/IP продают это в пакетах от нескольких долларов в месяц; для одного бота смотреть надо минимальный чек, а не цену за IP.
- **Не выдумывать цифры у провайдеров с JS-прайсом.** Не отрендерилось — так и сказать, а не подставлять «типичную» цену.
- **Датацентр ≠ смена отпечатка.** Прокси меняет IP, но не Canvas/WebGL/UA; там, где смотрят на отпечаток, нужен антидетект-профиль.
- **Регион, язык и таймзона должны совпадать с IP.** RU-IP + чужой `Accept-Language` — частая причина отказа там, где прокси технически проходит.
- **Сервис может блокировать всю подсеть хостинга.** Не прошёл один IP — пробовать другой ASN, а не продлевать тот же.
