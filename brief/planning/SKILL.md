# Life Planning

Персональное планирование жизни Василия. 5 горизонтов, интеграция с `t list`.

## Горизонты
| Горизонт | Команда | Что даёт |
|----------|---------|----------|
| Неделя | `python3 planning.py` | Тактика: по дням, приоритеты |
| Месяц | `--period month` | Цели по неделям |
| Квартал | `--period quarter` | Ключевые вехи |
| 3-5 лет | (задаётся в диалоге) | Видение |
| 10 лет | (задаётся в диалоге) | Миссия |

## Запуск
```bash
cd ~/.hermes/skills/brief/planning/scripts

python3 planning.py                    # неделя
python3 planning.py --period month     # месяц
python3 planning.py --period quarter   # квартал
python3 planning.py --now "2026-06-01" # от указанной даты
```

## 8 сфер (синхронизированы с evening-diary-brief)
- 🧑‍💻 Карьера — 30bit, деньги, проекты
- ❤️ Лима — отношения
- 👨‍👩‍👧 Семья/Родные
- 🧠 Развитие — английский, Python
- 💪 Здоровье/Спорт
- 🏠 Быт/Финансы
- 🤝 Друзья/Люди
- 🎮 Хобби/Отдых

## Что генерирует
1. **Стратегия** — статистика задач + приоритеты на период
2. **Тактика** — разбивка по дням с чек-пойнтами
3. **Оперативка** — ритуалы (morning brief → Deep Work → evening diary)
4. **Ритуалы** — воскресное ревью, план на следующий период

## Интеграции
- **task-manager:** cron воскресенье 20:00 МСК (0 18 * * 0)
- **evening-diary-brief:** те же 8 сфер, вечерний трекинг
- **t list:** подтягиваются реальные открытые задачи
