# Вечерний дневник

## ⏰ ШАГ 0 — ВРЕМЯ
```bash
TZ=Europe/Moscow date '+%Y-%m-%d %H:%M MSK'
```
Сервер UTC, пользователь MSK (+3). Всегда.

## ПОРЯДОК (строго, шаг за шагом)

### 1️⃣ Задачи
- `delegate_task → python3 ~/.hermes/scripts/task_display.py`
- Показать списком.
- **Спросить: «что делаем с висяками? удалить/сделать/перенести?»** Если есть задачи с 5+ переносами — подсветить.
- Если ответ «всё на завтра» → `t postpone` для всех без вопросов.
- Если назвали ID → обработать.
- Если пользователь говорит «готово, но не знаю как оформить дальше» (исследовал/написал план, но не реализовал):
  - **Не спрашивать в пустоту.** Сразу дать 2-3 конкретных варианта:
    1. ✅ done + создать новую задачу-цель в бэклог (без даты)
    2. ✅ done + сохранить суть как заметку в Obsidian
    3. ✅ done + поставить дедлайн на реализацию
  - Если выбрал бэклог — `t done <id>` по текущей, `t add "..." -p H/M -d none` с пометкой `backlog`.
- Если задача частично выполнена (посмотрел/исследовал, но не завершил):
  - Зафиксировать что именно сделано
  - Перенести с обновлённым комментарием: `t postpone <id>`
  - Если вскрылось расхождение (нейросеть сказала цену Х, по факту Y) — **записать это в заметку дня** или в тело задачи, чтобы не забыть при следующем подходе
- Если задача концептуально готова (research/planning phase completed), но пользователь не знает как оформить дальше:
  - Предложить конкретные варианты: ✅ done + создать задачу-цель в бэклог; ✅ done + запись плана в Obsidian; поставить дедлайн на реализацию
  - Не спрашивать «что делать?» в пустоту — сразу дать 2-3 варианта на выбор
- Для частично выполненных задач (посмотрел/исследовал, но не сделал) — зафиксировать текущий статус и предложить перенос с обновлённым контекстом
- Для задач с расхождением «ожидание vs реальность» (например, нейросеть назвала цену, а по факту дороже) — зафиксировать вывод в задачу и перенести

### 3️⃣ 8 сфер
Не «как день?», а пройтись по каждой кратко:
- 💼 **Карьера** — что по работе? 30bit?
- ❤️ **Лима** — как с ней?
- 👨‍👩‍👧 **Семья** — родители, близкие?
- 📚 **Развитие** — английский, Python?
- 💪 **Здоровье** — спорт, сон, еда?
- 🏠 **Быт/Финансы** — бюджет, дом?
- 🤝 **Друзья** — общение?
- 🎮 **Отдых** — что для себя?

Пользователь отвечает — я раскладываю кратко. Без аналитики.
