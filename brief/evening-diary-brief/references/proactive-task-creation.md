# Proactive Task Creation During Evening Diary

## Когда пользователь упоминает планы на завтра

Если в фазе **8 сфер** или **Рефлексия** пользователь говорит о делах на следующий день/ближайшее время:

1. **Сразу создавай задачи** через `t add "описание" -p H -d YYYY-MM-DD`
2. Не жди фазы «Минимум на завтра» из бонуса
3. Пользователь спросит «задачи создал?» — лучше чтобы они уже были

## Пример из сессии 2026-06-09

Пользователь на вопросе «На что обратить внимание завтра?» перечислил дела:
- Купить подушку в самолет для Лимы
- Утром пару кругов (давно не ездил)
- Найти машину к 7:30, проводить Лимy

→ Нужно было создать задачи сразу, а не ждать бонусной секции.
→ Пользователь спросил «задачи создал?» — создал постфактум.

## Правило

Если пользователь в любой фазе (кроме чисто ретроспективной) называет конкретные TODO — создавай задачу немедленно. Не откладывай.
