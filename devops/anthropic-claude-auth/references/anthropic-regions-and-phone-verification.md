# Anthropic: поддерживаемые страны и проверка телефона

Снято прямым заходом на официальные страницы (web-tools extract + curl), проверять периодически заново — список меняется.

## Источники (первоисточники, не блоги)

- `https://www.anthropic.com/supported-countries` — политика регионов и полный список.
- `https://support.claude.com/en/articles/8287232-verify-your-phone-number` — правила проверки номера.
- `https://support.claude.com/en/articles/14328960-identity-verification-on-claude` — верификация личности (документ + селфи, провайдер Persona).

## Что там написано (суть)

- Продукты Anthropic (Claude.ai, Claude Code, API) доступны только в перечисленных странах; **России в списке нет**.
- Политика прямо относит к неподдерживаемым: использование, находясь физически в неподдерживаемом регионе; компании, зарегистрированные/контролируемые из таких регионов.
- Телефон обязателен для **всех** новых аккаунтов, пропустить шаг нельзя.
- Не принимаются: VoIP, Google Voice, номера из приложений, стационарные и любые, не принимающие SMS.
- Один номер подтверждает максимум 3 аккаунта; **подтверждённый номер позже сменить нельзя** (освободить — только через поддержку).

## Ближайшие к России поддерживаемые страны

Узбекистан, Казахстан, Кыргызстан, Армения, Азербайджан, Грузия, Молдова, Турция, Сербия, Украина (кроме Крыма, Донецкой, Херсонской, Луганской, Запорожской областей), а также все страны ЕС, США, Великобритания, Канада, Япония, Индия и др.

Практический вывод: если у пользователя есть реальная связь со страной из списка (номер, карта, выезд), схема «номер + IP + карта из одной страны» собирается там; Нидерланды/Германия закрывают только IP-часть.

## Проверка серверного пути (что реально доступно с сервера в NL)

```bash
for u in https://claude.ai/ https://console.anthropic.com/ https://api.anthropic.com/; do
  printf "%-32s " "$u"
  curl -s -o /dev/null -w "http=%{http_code} t=%{time_total}s ip=%{remote_ip}\n" --max-time 12 \
    -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/126" "$u"
done
```

С сервера в Нидерландах: `claude.ai` отдаёт 403 обычному curl (антибот Cloudflare — не гео), `console.anthropic.com` — 301, `api.anthropic.com` — 404 на корне; всё это признак сетевой доступности. Роль `User-Agent` важна: без браузерного UA антибот режет раньше.

## Про оплату

Pro/Max оплачивается картой из поддерживаемой страны; российские карты за границей не работают. Карта и номер должны быть из той же страны, что и IP при регистрации, — иначе платёж или аккаунт отваливаются.
