# Clean Account Identity

Помощь, когда Василий (или worker) хочет завести «чистый»/стабильный аккаунт Google (или другой платформы) — создать самому не даёт, или нужен аккаунт, который переживёт проверки. Не даёт гарантий выживаемости — даёт проверенные факты, цены и развилки решений.

## Когда использовать

- «Не даёт создать/зайти в Google-аккаунт» (ошибки вида «на устройство слишком много аккаунтов», SMS-верификация не проходит)
- «Можно ли купить чистый аккаунт» / «где покупают gmail»
- «Как сделать стабильный identity удалённо за минимальную сумму»
- Нужен аккаунт под Google Ads / почту / сервис-авторизацию / YouTube

## Ключевые факты (Google, проверяемо)

1. **Дата-центровый IP (VPS) = красный флаг.** Создание аккаунта с IP сервера Google почти всегда режет (требует SMS, выдаёт «слишком много аккаунтов», не пускает). Ошибка «на одно устройство привязано слишком много аккаунтов» = Google зацепился за IP/отпечаток браузера, который уже создавал аккаунты (у дата-центров IP общие/переиспользуемые).
2. **Телефон — главный блокер.** Без номера для SMS создать НОВЫЙ аккаунт сейчас практически нереально. Купленный аккаунт создан на чужой номер: продавец может отозвать, 2FA не привязать без своего номера. Сначала решить вопрос номера (свой сим 100–300₽, узбекский +998 часто проходит лучше российского +7).
3. **Покупка аккаунта нарушает ToS Google.** Гарантия продавца — обычно «замена в течение N дней», не больше. Под Google Ads купленные аккаунты банят почти гарантированно (проверка плательщика).

## Стабильный identity = 3 компонента

1. **Чистый IP** — резидентный (домашний) или мобильный sticky, ОДИН на аккаунт. Не дата-центр.
2. **Стабильный отпечаток браузера** — антидетект-браузер, один аккаунт = один профиль. VPN/инкогнито отпечаток НЕ меняют (Canvas/WebGL/шрифты те же).
3. **Постоянство + прогрев** — не прыгать между IP/профилями; аккаунт должен «жить» до активных действий.

## Развилки по цели (спрашивать ПЕРВЫМ делом)

- **Google Ads** → купленные/серые аккаунты не вариант (бан с бюджетом). Нужен нормальный аккаунт + реальная проверка плательщика.
- **Просто почта/регистрации** → легально: создать с домашнего/мобильного IP + свой номер, либо Google Workspace за домен.
- **Сервис/API на сервере** → часто Gmail вообще не нужен (service account / OAuth). Проверить, прежде чем плодить аккаунты.
- **Не-Google платформы (Claude/Anthropic, OpenAI и т.п.)** → правила у каждой свои (поддерживаемые регионы, обязательная SMS с реального номера поддерживаемой страны, карта той же страны). Не переноси опыт Google на другие сервисы: для Claude ходи в навык `anthropic-claude-auth`.
- **Сначала спроси, что у пользователя УЖЕ есть** (аккаунт заведён? какой план? чем входит — Google/Apple/почта). Расписывать регистрацию человеку, который уже зарегистрирован, — гарантированное «ты не понял задачу».
- **Массово «на поток»** → серая зона, банят пачкой; антидетект + прокси + прогретые номера, выживаемость не гарантирована.

## Pitfalls

- НЕ советовать покупать аккаунт, пока не выяснена цель — под Ads это сожжённые деньги.
- НЕ обещать «чистоту» купленного аккаунта: пачки с одних IP/телефонов Google видит по внутренним связям.
- Дата-центровые прокси дешевле, но для Google бесполезны — только резидент/мобильный.
- Часовой пояс/язык профиля должны совпадать с регионом прокси (немецкий IP + московское время = частая ошибка).
- Проверка профиля перед работой: browserleaks.com (Canvas/WebGL/шрифты), pixelscan.net (согласованность), whoer.net/ipleak.net (утечки WebRTC/DNS).
