# US-00a воронка — детали (31.08.2026)

Карта шагов: `docs/us00a-platform-funnel/README.md` + `steps/01..10`. Все шаги реализованы (BACK-000, BACK-08, T-10..T-14, T-17), кроме rate-limit/IP-фрода (шаг 10 — partial).

## Модель триала (решение Василия 31.08)
1. Викторина на лендинге `/quiz` → только лид (компания НЕ создаётся автоматически).
2. Первые 7 дней бесплатно — лид пробует на **ботах и админке платформы** (демо-доступ), ничего не настраиваем.
3. Оплатил подписку во время викторины (и не отменил) → владелец платформы связывается и **вручную настраивает** компанию лида.
Тексты везде под эту модель: «7 дней бесплатно на наших ботах и админке; оплатите — настроим вашу платформу».

## Публичные эндпоинты воронки (src/interface/api/public/quiz.py)
- `GET /api/public/platform-bot` → `{username: worker, client_username: client}` (тенант platform; None → фронт не показывает кнопки)
- `POST /api/public/quiz-lead` — лид (201), анти-дубль по username, 422 при пустом tg_username, событие quiz_finished, уведомление супер-админу
- `POST /api/public/quiz-lead/{id}/pay-test` — заглушка оплаты:
  - лид → PAID + Payment(provider=test, amount по плану p1=500k/p2=875k/p3=1250k UZS, дефолт 500k) + событие PaymentPaid (уведомление «💰 Оплата …»)
  - `trial_ends_at = now + 7 дней` если не задан
  - идемпотентна (LeadService.mark_paid): повтор не дублирует Payment
  - 404 для неизвестного лида

## Deep link с меткой лида (отслеживание пользователя)
- Фронт: кнопка «Написать боту» = `https://t.me/<worker>?start=lead_<id>` (id из ответа quiz-lead)
- Бот (worker_start `cmd_start_lead`, regexp `^lead_(\d+)$`):
  - username из payload-лида совпал с username отправителя (без @, lower) → `lead.telegram_id = from_user.id` + «👋 Привет! Заявка получена…»
  - не совпал / лида нет / telegram_id уже чужой → общее «Заявка получена, скоро свяжемся» (без деталей)
  - хендлер регистрируется ДО `cmd_start` (aiogram берёт первый подходящий фильтр)

## Бот /start для незнакомцев (бот-викторина УПРАЗДНЕНА 31.08)
- FSM-викторина в боте дублировала веб — убрана из активного сценария: `worker_quiz` отключён от `worker_bot` (роутер остаётся, тесты test_worker_quiz сами его подключают)
- Неизвестный `/start` → приветствие + одна кнопка «📝 Пройти викторину» (/quiz); без «Войти в админку» (лишние запросы не нужны)
- `/start quiz` (старый CTA) → то же приветствие/меню, не викторина
- CTA «Для бизнеса» на визитке — `t.me/<worker>` без payload
- Супер-админ (SUPER_ADMIN_TELEGRAM_ID) → меню админки + «🌐 Моя визитка» (без изменений)
