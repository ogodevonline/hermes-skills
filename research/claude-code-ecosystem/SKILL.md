# Claude Code / Agent Skills Ecosystem

Карта экосистемы Agent Skills (2026): когда Василий спрашивает «что появилось полезного для Claude Code» или просит найти агента-скилл под задачу (заработать, личный коучинг, «узнай меня через интервью», автоматизация) — этот навык даёт проверенные находки, порядок верификации и предупреждения по безопасности.

## When to Use

- «Найди плагины/скиллы/агентов для Claude Code» — заработок, бизнес, продуктивность
- «Есть ли агент, который проведёт интервью, узнает про меня всё, поможет сменить направление/мышление»
- Любой подбор Agent Skills / Claude-плагинов из открытой экосистемы

## Ключевой факт: формат открытый

Agent Skills = папка с `SKILL.md` (+ `scripts/`, `references/`). Стандарт [agentskills.io/specification](https://agentskills.io/specification) принят Claude Code, OpenAI Codex, Cursor, Gemini CLI **и Hermes**. Установка: `~/.claude/skills/<name>/` (пользовательский), `.claude/skills/` (проектный), `/plugin marketplace add owner/repo`.

**Вывод для Василия:** рекомендация не требует покупки Claude — совместимый скилл ставится прямо в Hermes (`~/.hermes/skills/`). Всегда озвучивать это в ответе.

Термины не путать (дизамбигуация Snyk):
- `CLAUDE.md` — постоянная память проекта (не capability)
- Slash-commands — шаблоны промптов, влиты в Skills (argument-hint)
- MCP-серверы — процессы с инструментами/API
- Плагины — бандлы (skills + agents + hooks + MCP) для дистрибуции
- Skills — папки со SKILL.md, прогрессивная загрузка (name+description ≈100 токенов на старте)

## Порядок работы (проверен 02.09.2026)

1. Поиск: `~/.cargo/bin/web-tools search "..." --source google --no-region` (EN-запросы, экосистема англоязычная).
2. Проверка репозиториев — GitHub API (правило 16 навыка web-search-scraper): точное имя, звёзды, живость. ⚠️ `gh` с устаревшим `GH_TOKEN` из `~/.hermes/.env` падает — не чинить. Для ПУБЛИЧНЫХ репозиториев `curl -s https://api.github.com/...` работает БЕЗ заголовка Authorization: протухший токен даёт 401, отсутствие токена — 200 (лимит ~60 req/ч на IP). Токен нужен только для приватных репозиториев и search API с высоким лимитом.
3. Извлечение README/страницы через `web-tools extract` (github.com читается) — понять ЧТО скилл реально делает, а не верить сниппету.
4. Рекомендовать только проверенное, с URL источника и пометкой ✅ проверено.
5. Подстройка под контекст Василия: заработок = его воронки/попкорн/lead-platform; коучинг = osmysl/рост зарплаты. Предлагать конкретный следующий шаг (поставить скилл сюда и запустить интервью).

## Безопасность (обязательно упоминать)

Snyk ToxicSkills: **36% просканированных скиллов содержали prompt injection**, 13.4% — критические уязвимости. Перед установкой читать `SKILL.md` и скрипты глазами. Психологические/коучинговые скиллы — любимое место для скрытых манипуляций.

## Pitfalls

- **mcpmarket.com отдаёт HTTP 429** при частых extract — ретрай позже или ищи альтернативный источник, НЕ вывод «сайт мёртв».
- **skillsllm.com** — страницы скиллов содержат security-скан и число звёзд: удобно для быстрой верификации.
- Сниппеты поиска — кандидаты, не факты. Подтверждение — README на GitHub.
- Описания в сниппетах часто пишут «интервью-коуч» про собеседования на работу (noamseg, raphaotten) — это НЕ то, что Василий называет «интервью, чтобы узнать меня». Различать job-interview коучинг и личный/экзистенциальный коучинг.

## Verification

- Каждая рекомендация в ответе имеет URL источника и пометку проверки.
- Перед «поставить скилл» — посмотреть SKILL.md на prompt injection.
- Если ответ обещает «запущу интервью» — запустить, не оставлять обещанием.
