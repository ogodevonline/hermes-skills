## Оффер: продавать РЕЗУЛЬТАТ, не инструмент

Люди не покупают «парсер с диспетчером» и не покупают «бота». Покупают:
- «каждое утро свежие данные/упоминания в TG/Excel» (подписка)
- «клиенты записываются сами, без звонков менеджеру» (бот для записи)

За результат платят 80–200к ₽, за «бота» — 5к. Разница в цене в 10 раз.

## MVP-тест гипотезы без кода (7 дней, concierge)

Техника готова на 80% — MVP = продажи руками, НЕ платформа/биллинг/API.

1. День 1: оффер одной строкой + цена (Москва 15–30к ₽/мес). Страница-заглушка или просто сообщение.
2. День 2–4: 20–30 точечных касаний (см. каналы ниже). Критерий: 3–5 ответов «покажите пример/сколько стоит».
3. День 4–5: пример отчёта на ЖИВЫХ данных (парсеры уже работают), оформить руками (concierge).
4. День 6–7: первый платящий, предоплата за месяц. Только потом автоматизация доставки.

Метрика успеха: 20 касаний → 3–5 интересов → 1–2 оплаты = гипотеза подтверждена.
0 интересов из 20 = не подтверждена — менять оффер/рынок/цену, НЕ код.
НЕ делать до первых денег: доводка lead-platform, биллинг, API, лендинг-платформа.

## Каналы холодных продаж БЕЗ знакомых (Москва)

1. **Личные сообщения владельцам бизнесов с активным TG** — точечно, НЕ спам-рассылка. Найти: tgstat.ru (каналы по темам) + 2GIS (бизнесы района). 10–15 персональных/день.
2. **Личные визиты в бизнесы района** (барбершоп, стоматология, салон, автосервис) — показать пример отчёта на телефоне. Страшно первые 3 раза, потом нормально. Сам себе знакомство.
3. **Биржи** (Kwork, FL.ru, Profi.ru) — спрос есть (Profi: 306 исполнителей парсинга TG), старт для первых кейсов и отзывов, НЕ для больших денег (демпинг).
4. **Один публичный кейс** — «вот что пишут о нише за неделю» на vc.ru/TG — люди приходят сами.

Воронка: 20 касаний → 3–5 ответов → 1–2 сделки. Отказы — цифры, не про личность.

## Рынок мониторинга TG/новостей (проверено 09.2026)

- Корпоративные платформы (Brand Analytics, Медиалогия, ПрессИндекс) дороги: от 50к ₽/мес.
- Копеечные разовые выгрузки (vygruzka.online «от 20 ₽») — демпинг, денег нет.
- ПУСТАЯ СЕРЕДИНА: шаблонный регулярный мониторинг для малого бизнеса/SMM-агентств 10–30к ₽/мес.
- Покупатели по вероятности: SMM/PR-агентства (белый сервис) → малый бизнес → новостные агрегаторы.
- TG-каналы и сайты = стабильный хлеб; IG/YouTube нестабильны (капчи/сессии — уже проходил).
- Публичные данные — ок; личные контакты людей — нет (кейс Habr отказывался от «баз ЛПР»).

## API vs отчёты (если спросит)

- Отчёты/дайджест: покупает бизнес без технарей, старт 1-2 нед, продаёшь боль.
- API: покупают разработчики, нужен SLA/аптайм/доки/биллинг — тяжёлое обязательство.
- Рынок API-новостей: $29–500/мес (NewsAPI, datastreamer, Mediastack).
- Рекомендация: отчёты первыми (быстрые деньги, нетехнические клиенты), API вторым слоем на том же движке после 3–5 платящих клиентов.

## Цифры-якоря из кейсов (детали: online-earning-case-bank.md)

- Парсинг: средний чек 15к ₽/мес, 80% клиентов — регулярная подписка (Habr 20 млн ₽/год).
- Чат-боты: простой 15–40к ₽, автоворонка+CRM+AI 80–200к ₽, абонентка 5–25к ₽/мес × 10 клиентов = 50–150к ₽/мес фонового дохода (BotHelp).
- AI-автоматизация: проект $500–700 + поддержка $200–300/мес; маржа 70–85%; спрос > предложения в 10× (axdigital).
