## Рецепт разведки каталога (без установки)

```bash
cd ~/.hermes/hermes-agent
hermes skills search crypto|bybit|trading          # список + trust (official/community)
hermes skills inspect "<DisplayName>"              # НУЖНО точное отображаемое имя в кавычках;

```
`inspect` показывает полный SKILL.md превью: license (Proprietary ⇒ платный), `requires.env/bins`, цену прямо в тексте.

## TradingView: что реально есть (первоисточники проверены)

- **Официального торгового API НЕТ.** TV не брокер. Официальное: Datafeed/Charting Library (B2B) + **webhook-алерты** (POST на твой URL).
- Дока TV (support/solutions/43000529348): webhooks — только порты 80/443, таймаут 3с, IPv4, allowlist IP 52.89.214.238 / 34.212.75.30 / 54.218.53.128 / 52.32.178.7.
- **Webhook = только платный тариф.** Официальная дока Bybit говорит это прямым текстом («необходима платная подписка Essential/Plus/Premium»). Free план: 3 ценовых алерта, 0 технических, 0 webhooks (tv-hub, 07.2026). Цены: Essential ~$13/мес, Plus ~$25/мес (supa.is, 04.2026 — вторичный, сверять tradingview.com/pricing).
- **Bybit webhook signal trading — бесплатно со стороны биржи**, URL генерит сам Bybit (Торговать→Инструменты→Сигнальная торговля с веб-хуком), только деривативы, только one-way режим, стратегия (не индикатор) в Pine. Т.е. платный шарнир ровно один — TV-подписка.
- Неофициальный Mathieu2301/TradingView-API — реверс их WebSocket, бесплатно, но **нарушает ToS TV** (бан аккаунта).
- Бесплатная замена «TV-алертов»: переписать Pine-условие в Python + ccxt-данные + алерты в Telegram. Для микро-капитала это и есть правильный rung.

## Гео/санкционный риск РФ (Bybit)

Россия НЕ в restricted-списке Bybit (кроме Крым/ДНР/ЛНР/Севастополь), KYC паспорт обязателен. НО: с весны 2026 волна заморозок аккаунтов россиян по «историческим санкционным связям» после 20-го пакета ЕС (24.05.2026) — источник vc.ru/3003370 (вторичный; первоисточник: bybit.com/help-center/Service-Restricted-Countries). Для микро-эксперимента — **Bybit Demo Trading** (бесплатно, sandbox-ключи, ccxt `sandboxMode`) — та же проверка «работает/нет» без риска заморозки.

## Скелет вердикта пользователю

1. Чего нет: «навык сам печатает деньги» — любой такой позидинг = скам или подписка ($97 кейс).
2. Что есть: классы — исполнители (нужна стратегия) / сканеры (нужен капитал) / аналитика read-only.
3. Прогнать бесплатно на живых данных (бэктест, funding, мин-ордера) — цифры решают.
4. Считать все подписки в % от капитала пользователя; при <$1k почти любая SaaS-связка мертва.
5. Порядок: backtest → demo/paper → live только tiny.
