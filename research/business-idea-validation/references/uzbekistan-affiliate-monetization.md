# Affiliate / faceless-монетизация из Узбекистана (срез 2026)

Конденсат исследования «заработать на партнёрках через переделанные вирусные ролики» (faceless affiliate marketing), август 2026. Проверено по web-tools CLI (первоисточники в таблице).

## Ключевой принцип
- **Доступ к партнёрке определяется страной аккаунта/документов/IP, а НЕ картой.** Долларовая карта решает вывод денег, но не доступ к программе. VPN на входе не обманет сверку при выплате → бан + заморозка комиссий. Серые обходы (фейк-документы, VPN-фарм) = потеря денег; на них зарабатывают авторы курсов, а не исполнители.

## Реальные цифры (не маркетинг из рилсов)
- TikTok Creator Rewards: $0.40–1.00 за 1000 просмотров.
- Медиана faceless-аккаунтов: $0–50/мес. Топ-кейсы ($44k, «$900–1000 в первый месяц») — выбросы и само-отчёты.
- Практики (Reddit/BlackHatWorld 2026): faceless = «нишевой контент-бизнес, реальная работа», НЕ пассивный доход. Рабочая схема — органический трафик TikTok/YouTube Shorts на нишу + партнёрка.

## Риск модели «100 роликов/день из чужих»
- = **reused content** → демонетизация/бан. YouTube ужесточил политику (с 15.07 перестаёт платить за переделанное/скопированное), TikTok режет повторный контент так же.
- Разумный объём: 1–5 роликов/день СВОЕГО контента, не 100 копий.

## Что реально построить для УЗ
Пайплайн: выбор товаров с ePN → LLM-скрипт → TTS-озвучка → ffmpeg-монтаж → полуавтозагрузка (YouTube Data API разрешает автопостинг; TikTok/IG — полуавто). Рынок — русскоязычный СНГ (УЗ + РФ + KZ).
