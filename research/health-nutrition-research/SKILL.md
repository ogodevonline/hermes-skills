# Health & Nutrition Research — для Василия

Класс: симптомы (вздутие, туман в голове, усталость), «правильное питание», разбор тезисов блогеров о еде, страхи («в яйцах глисты»), «что мне есть». Медицинские вопросы у Василия — повышенная ставка (импланты, костная пластика, удаления), советы из головы запрещены.

## Стандарт глубины (его прямое требование)
Василий злится на поверхностный разбор и требует «копнуть глубже, докопаться до сути». Ответ на 3 общих ссылки + «сходи к врачу» = провал. Глубина =
1. **Разобрать КАЖДУЮ его гипотезу** отдельно (молочка, глютен, яйца/паразиты, плохое жевание…) — вердикт «подтверждается / ложный след / не проверено» + механизм одной фразой.
2. **Добавить гипотезы, которых он не назвал**, но которые следуют из его истории: лекарства после операций (антибиотики → микрофлора), дефициты из-за исключённого (не ест мясо → железо/ферритин), стресс/переезд, сон.
3. **Посчитать его дозу против порога из источника** (пример: 2–3 стакана молока ≈ 24–36 г лактозы при пороге ~12 г = 1 стакан, NIDDK). Цифры с расчётом, не «много молочки».
4. **Задать вопросы, которые меняют вывод** (пил ли антибиотики и сколько дней; давно ли симптом; после чего хуже).

## Процедура
1. Перед ответом выписать список гипотез (его + свои). Уточнения спрашивать до ответа только если без них вывод не построить — иначе разбор, вопросы в конце.
2. Поиск: `~/.cargo/bin/web-tools search` → **читать полный текст** первоисточника через `web-tools extract` + `grep -iE` по ключевым словам. Приоритет: NIDDK/NIH, NHS, FDA/CDC, Роспотребнадзор, PubMed/PMC обзоры, КиберЛенинка (данные по РФ), клин. рекомендации МЗ РФ. СМИ-пересказы (Mirror, Daily Star, блоги) — не источник.
3. Extract запускать **отдельными параллельными terminal-вызовами** по 2–4 URL, а не одним большим скриптом в execute_code: большой скрипт ждёт подтверждения, при молчании пользователя оно истекает и весь сбор теряется.
4. В ответе различать «прочитал текст» и «видел только заголовок/аннотацию» — второе помечать явно. Заголовок исследования не выдавать за прочитанный вывод.
5. Ограничение исследования (обзор про пожилых, выборка, страна) — одной оговоркой.
6. Финал: план под его реальные условия (ниже) + что отслеживать + какие анализы/к какому врачу + красные флаги.

## Контекст Василия для планов питания
- Жевать тяжело (импланты): в основном передними зубами → еда **мягкая, не жидкая**: каши, пюре, омлет/яйца вкрутую, рыба (минтай/треска), фарш/котлеты индейка-курица, тушёные/запечённые овощи.
- Готовить умеет мало, хочет минимально; **заготовки на несколько дней нельзя** (холодильник у бабушки занят) → рецепты на один день, 10–15 минут.
- Покупает готовое во ВкусВилле; бюджет быт ~24к/мес.
- Эксперимент-исключение (напр. 2 недели без молока) + ежевечерняя оценка 1–5 (вздутие, голова) — предложить напоминание.

## Pitfalls
- Модные страхи (глютен у не-целиаков, «паразиты в яйцах») не подтверждать и не отметать без первоисточника — см. references.
- Не ставить диагноз: «версия, проверяется так-то (тест/исключение/анализ)».
- Instagram-профили блогеров через extract не открываются (429) → попросить скрины/пересказ тезисов, разбирать тезисы по первоисточникам.
- Формат: заголовки-гипотезы с вердиктом, ссылка у каждого утверждения, в конце план нумерованным списком и вопросы. Без таблиц (Telegram).
