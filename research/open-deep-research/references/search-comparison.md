# Search Engine Comparison for Open Deep Research

## Tavily (текущий — уже подключён)

| Аспект | Оценка |
|--------|--------|
| **Бесплатный tier** | ✅ 1000 запросов/мес |
| **Международные темы** | ✅ хорошо (технологии, тренды, вики) |
| **RU/UZ контент** | ❌ плохо — пустые результаты для локальных запросов |
| **Цены в России** | ❌ не находит |
| **OLX/Avito/объявления** | ❌ не находит |
| **API ключ** | ✅ уже в researcher/.env |

**Вердикт:** годится для международных исследований. Для RU/UZ — бесполезен.

---

## Brave Search API

| Аспект | Оценка |
|--------|--------|
| **Цена** | $5/1000 запросов (бесплатно $5 кредитов = 1000 запросов) |
| **Кредитка** | ❌ требуется при регистрации |
| **Качество поиска** | хорошее, но платный |
| **RU/UZ контент** | лучше Tavily, но не идеал |
| **MCP сервер** | есть (`@anthropic/mcp-server-brave-search`) |

**Вердикт:** не подошёл из-за требования кредитки и платной модели.

---

## Yandex XML (search.py — текущий Hermes инструмент)

| Аспект | Оценка |
|--------|--------|
| **Бесплатно** | ✅ да (лимит по запросам/день) |
| **RU/UZ контент** | ✅ отлично |
| **Международные темы** | ⚠ среднее |
| **API** | через XMLStock |
| **Скрипт** | `search.py` в навыке `web-search-scraper` |

**Вердикт:** лучший для RU/UZ. Но Open Deep Research не поддерживает Yandex XML как search_api.

---

## Что нужно для интеграции Yandex XML в ODR

Open Deep Research поддерживает search_api = "tavily" | "openai" | "anthropic" | "none".

Чтобы использовать Yandex XML:
1. Написать кастомный tool на основе `search.py`
2. Зарегистрировать его как MCP tool или встроить в `get_all_tools()`
3. Установить search_api = "none", передать кастомный tool через tools

Текущий runner скрипт использует только Tavily. Для RU/UZ deep research нужно расширение.
