# Кейс: «AI-нейроблогер на affiliate» — reel от 02.10.2026

Разбор рилса https://www.instagram.com/reel/Dd_gpY6yFze/ (91 сек, русский, автор @klymenko_bogdan,
399 лайков / 539 комментов на дату разбора). Задача Василия: «надо узнать реально ли это
работает, если да, то как мне это автоматизировать».

Транскрипция: скачать `yt-dlp -o "reel.%(ext)s" URL` → ffmpeg в wav 16k mono → faster-whisper
(см. навык `video-translate`). Автор говорит по-русски — `lang=ru prob=1.00`.

## Что заявлено в рилсе (декомпозиция)

Дословная схема:
1. ChatGPT: «популярный бизнес на 2027» → ниша «товары для домашних животных».
2. Создать персонажа, найти товар (пример — коллаген для собак).
3. Картинка персонажа + фото товара → персонаж с товаром в руках.
4. GPT пишет короткий сценарий + автоперевод на английский.
5. Загрузка в **Kling** — «оживляет», персонаж сам говорит на английском.
6. Ролик ~30 секунд, без съёмки и без питомца.
7. Публикация в IG/TikTok/YouTube Shorts → реферальная ссылка → % с продаж.

Классификация: НЕ нейроблогер, а **автоматизированная affiliate-витрина** с шаблонным
циклом «нашёл товар → сгенерировал ролик → получил 1–3% с продажи». Воронка в рилсе одна —
ссылка в шапке профиля на «инструкцию по слову ТЕЛЕФОН» (бесплатный лид-магнит).

## Что реально (проверено)

**Технически — да.** Пайплайн на Hermes-сервере собирается из: `image_generate` (картинка +
`reference_image_urls` для персонажа с товаром) → `text_to_speech` (озвучка) → внешний API
оживления → ffmpeg-склейка. Kling API официальный: https://kling.ai/document-api.
⚠️ Локально Kling НЕ запустить (сервер 4 CPU / 4 ГБ RAM / без GPU) — шаг оживления только
через внешний API, ~$0.3–1 за ролик. Дешёвая альтернатива: статичная картинка + озвучка.

**Деньги — ловушка.** Разложено на цифрах:
- Amazon Associates US: физические категории **1–4,5%**, pet supplies ≈ 3%
  (точную ставку видно только в своей rate card — публичная таблица Amazon прячет за логином,
  `affiliate-program.amazon.com/help/operating/schedule` отдаёт 302 на sign-in).
- Товар $30–60 × 3% = **$1.20–1.80 с продажи**.
- Окно атрибуции Amazon — **24 часа** (клик должен быть свежим).
- С **14 апреля 2026** Amazon исключил продажи с платной/бустовой рекламы (его What's Changed) —
  остаётся только органический охват.
- Оплаченный креатив (Kling) в эти $1.20 не входит: до объёма себестоимость съедает маржу.
- Реалистично: $50–200/мес на первые 2–3 месяца, 1 аккаунт, 4–5 рилков в неделю.

Источник разбора комиссий: https://amawp.com/amazon-associates-commission-rates/
(обновлён 01.10.2026, таблица сверена с Fee Schedule 25.08.2026). Важная оговорка оттуда же:
«halo»-изменение 2026 относится к контенту на самом Amazon, а не к ссылкам на своём сайте —
частая ошибка при пересказе.

## Риски, которые рилс не упоминает

- **Пометка рекламы обязательна.** РФ — ст. 18 ФЗ-303 «О рекламе»; за рубежом FTC
  Endorsement Guide требует раскрытия в самом посте (`#ad`), а не только в описании.
- **Маркировка AI-контента.** Meta и TikTok в 2026 помечают сгенерированное; Instagram режет
  охваты профилям, где весь контент синтетический и нет лица/реальных кадров.
- **Один шаблон на N аккаунтов = бан по паттерну.** Ниша + шаблон + товар должны различаться.
- Публикацию нельзя делать полностью на автопилоте без ревью: нужен human-in-the-loop.

## Как отвечать на «как автоматизировать»

Правильная последовательность (ВАСИЛИЙ ЦЕНИТ именно такой порядок):
1. **Сначала проверка спроса, не пайплайн.** 10 роликов в 1 аккаунт, замерить просмотры.
   Иначе потратишь время на конвейер, который производит непрочитанное видео.
2. Потом сборка: генерация батча → рендер → черновик Василию на утверждение → постинг.
3. Cron в 3 слота/день, публикация только после явного «ок».
4. Спросить ДВА вопроса до кода: (а) какая гео/партнёрка — determines товары и язык роликов;
   (б) бюджет на Kling API — «0 ₽» (статика + озвучка) или «$30–50/мес» (полное оживление).

## Универсальный вывод по классу «faceless-контент + affiliate»

- **Всегда тащи юнит-экономику в штуках:** цена товара × ставка = $ с продажи → сколько
  продаж нужно на $X/мес → сколько рилков при конверсии Y. Озвучь это числами, иначе
  «бизнес готов за 30 секунд» принимается за чистую правду.
- **Проверяй гео ДО расчёта маржи.** Если партнёрка не выдаёт аккаунт пользователю — вся
  арифметика бессмысленна, даже при идеальной механике.
- **Проверь изменение правил у самой партнёрки** (дата, что именно изменилось) — Amazon в 2026
  дважды резал выплаты без изменения опубликованных процентов.
- **Страховой ответ (вариант «0 ₽»)** всегда упоминать: не запускать видео-креатив ради копеечной
  комиссии, пока не проверена экономика.
