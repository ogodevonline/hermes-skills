# Self-Check Checklist

Перед `kanban_complete` ответь на ВСЕ вопросы.

```
## Self-Check

### 1. Конкретные числа?
[ ] ДА — все цены/даты точные (1234, а не «~1000», «от 1 до 2», «около»)
[ ] НЕТ — есть диапазоны → НЕ отдавать, доработать

### 2. Источники?
[ ] ДА — у каждого числа есть ссылка (URL или название сайта)
[ ] НЕТ — часть чисел без источника → НЕ отдавать, доработать

### 3. 2+ источника?
[ ] ДА — каждое число подтверждено ≥2 независимыми источниками
[ ] ДА, но одно из чисел только из 1 источника — помечено «требует верификации»
[ ] НЕТ — есть числа без второго источника И не помечено → доработать

### 4. Формат?
[ ] ДА — отчёт по одному из шаблонов (price/market/fact/general)
[ ] НЕТ — отчёт неструктурированный → доработать

### 5. Неверифицированные данные?
### 5. Неверифицированные данные?
[ ] ДА — секция «Неверифицировано» заполнена
[ ] НЕТ/НЕ ПРИМЕНИМО — все данные проверены

### 6. Контекстуализация?
[ ] ДА — варианты отфильтрованы под профиль пользователя (стек, уровень, страна)
[ ] ДА — но профиль неизвестен, сделана пометка «generic, уточнить пользователя»
[ ] НЕТ — generic overview без учёта пользователя → доработать

## Результат

- Все 5 ✅ (или 6 если применимо) → `kanban_complete(summary, metadata)`
- Любой ❌ → `kanban_block(comment: что именно не прошло)`
