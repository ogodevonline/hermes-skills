# Study Reminder — Cron-скрипт напоминания об учёбе

Запускается как cron-задача. Проверяет, занимался ли Василий сегодня, и отправляет короткое напоминание.

## Тригер

Cron-джоб. Время — переменная (утро/день/вечер).

## Определение тона по времени

| Время | Тон | Характер |
|-------|-----|----------|
| 06:00–09:00 | бодрый, энергичный | «Воскресное утро — отличный момент ворваться» |
| 11:00–15:00 | деловой, нейтральный | «День в разгаре — есть время на сессию» |
| 17:00–20:00 | тёплый, ободряющий | «Вечером самое время — подводим итоги дня» |

## Формат сообщения

⚠️ **Жёсткие правила форматирования:**

1. **Ровно 2-3 предложения.** Не больше.
2. **Коротко и по делу.** Без воды, без размышлений вслух, без объяснений «почему важно».
3. **Минимум эмодзи.** Максимум один — ⏰ в начале. Без эмодзи-спама.
4. **На русском языке.**
5. **Первый абзац:** приветствие/время суток + констатация факта.
6. **Второй абзац:** прогресс (что и когда делал в последний раз) + призыв к действию.
- `/english` или `/собеседование` — короткая строка без описания.
8. **Если уже занимался сегодня:** «Молодец, держи темп» — одно предложение, без продолжения.

## Проверка: занимался ли сегодня

### Шаг 1 — Привычки (через `t habits`)

```bash
~/.local/bin/t habits
```

В выводе искать привычки 5, 6, 7 с названием «Английский или Python»:
- `⏳` = не сделано
- `✅` = сделано (возможно `✅xN` при нескольких подходах)

У Василия 3 временных слота: 09:00, 14:00, 18:00.
Если хотя бы один слот ✅ за сегодня — считается, что занимался.

### Шаг 2 — Vault (если нужна детализация)

**Английский:** проверить последнюю lesson-NNN в YouTube-папке:
```bash
ls -lt ~/hermes-vault/Learning/English/youtube-*/lesson-*/story.md | head -3
```

**Python / Собеседования:** проверить последнюю сессию Colloquium:
```bash
ls -lt ~/hermes-vault/Learning/Colloquium/Book-001-the-last-python-dev/session-*/session.yaml | head -3
```

читать `state.yaml`:
```bash
cat ~/hermes-vault/Learning/Colloquium/state.yaml
```

## Логика сообщения

```
ЕСЛИ (хотя бы одна привычка ✅ за сегодня):
    → "Молодец, держи темп." (1 предложение)

ИНАЧЕ:
    → ⏰ [время суток], [имя]!
    → [Что и когда делал в последний раз] — [призыв]
    → /english или 🐍 /python

    ЕСЛИ (прошло >7 дней с последней сессии любого предмета):
        → добавить ободряющую фразу про восстановление momentum
```

## Pitfalls

1. **`t habits` может быть медленным** — терпеть, результат приходит через 1-2 сек.
2. **Не генерировать урок** — только напоминание. Без вызова english / python-road скриптов.
3. **Проверять обе привычки** — может быть сделана в один слот, а не три.
4. **`colloquium` — новый формат подготовки к собеседованиям** — заменил python-road. Команда `/собеседование`. 100 сессий: алгосы + system design + AI engineering. Проверять `Colloquium/state.yaml`.
5. **Не использовать `python3 -c` с SQLite для проверки привычек** — использовать только `~/.local/bin/t habits`.
