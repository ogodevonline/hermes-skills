## Квартиры и аренда

Поддерживаются через колонку `property_type` в БД. Парсер OLX сам определяет тип (house / apartments). Тип нормализуется: `house`/`houses` → `house`. 

В отчёте фильтр **Type** позволяет выбрать "house" или "apartments".

### Источник аренды (rent)

Для поиска **съёмных квартир** добавлен отдельный источник `rent` в config.json:

```json
{
  "name": "rent",
  "base_url": "https://www.olx.uz/nedvizhimost/kvartiry/arenda-dolgosrochnaya/nukus/",
  "max_pages": 5
}
```

Цены аренды: 1 200 000 — 5 000 000 сум/мес (против 50-400 млн сум продажи).

⚠️ Фильтры отчёта (ползунки цены, цветовая маркировка) заточены на **продажу**. При генерации отчёта для аренды нужно адаптировать `nukus_html_builder.py`: изменить цветовую шкалу (зелёный < 2 млн, жёлтый 2-3 млн, красный > 3 млн) и ползунки цены (0-10 млн, min=0 а не 50). Баг `min=50` починен 16.07.2026 — теперь min=0.

## Питфоллы

0. **⚠️ .html НЕ отправлять пользователю на телефон.** Файл .html, отправленный через send_document, открывается на Android как **Excel** (пользователь говорит «ты скинул Excel»).
   - **Вместо .html:** отправить **.xlsx** (через MEDIA: — работает, колонка «Заметки» для пометок) + **простой текст** со списком топ объявлений и ссылкой на OLX.
   - .html сохранить локально и сказать путь для открытия на ПК: `file:///home/hermes/.hermes/cache/documents/nukus_report.html`
1. **MEDIA не работает для .html** — только python-telegram-bot send_document. Для .xlsx MEDIA работает.
2. **database is locked** — возникает в `cron_report.py` (старый скрипт). Две конкурирующие SQLite-коннекции: основная держит транзакцию, `update_db()` открывает вторую. Решение: использовать `gen_report_interactive.py` (только чтение, без записи).
3. **WAL-файлы** — после kill остаются `nukus.db-wal` / `nukus.db-shm`. Удалять перед перезапуском.
4. **Запуск с pipe** — не делать `... | tail -5` в фоне. Tail буферизирует. Запускать без pipe.
5. **Полный парсинг через LLM** — 5-10 минут. Для быстрой выдачи — прямой SQLite (шаг 2, без шага 1).
6. **Только ручной запуск** — крон запрещён.
7. **JS: функция фильтрации и `onchange`.** При рефакторинге не переименовывать функцию фильтрации в JS без обновления `onchange`-атрибутов в HTML-шаблоне. Фильтры вызывают `a()`, которая должна вызывать `f()` (основной фильтр), а не `sortRows()`. Иначе фильтры перестают работать — пользователь меняет селект, а rows не фильтруются.
8. **`gen_report_interactive.py` зависит от `nukus_html_builder.py`.** Оба файла должны лежать в одной директории. При запуске `cd` в директорию скриптов — иначе `ImportError`. Команда: `cd ~/.hermes/skills/productivity/nukus-new/scripts && python3 gen_report_interactive.py`.
9. **`send_html_report.py` читает токен из `.env`.** Строка `TELEGRAM_BOT_TOKEN=*** — реальный токен, НЕ закомментированный. Проверять что парсинг не сломан (раньше была SyntaxError из-за незакрытой кавычки на строке с `***`).
10. **bs4 / Python path.** System python3 (3.12) не имеет beautifulsoup4. Парсер надо запускать через Hermes venv: `/home/hermes/.hermes/hermes-agent/.venv/bin/python3`. Если bs4 отсутствует: `uv pip install beautifulsoup4 requests`. Проверка: `python3 -c "import bs4"`.
11. **Пользователю нужна аренда, не продажа.** Цены аренды 1.2-5 млн сум, продажи 50-400 млн. Ползунки отчёта по умолчанию не подходят — адаптировать nukus_html_builder.py под аренду при `/houses` запросе.
12. **WAL-файлы и kill парсера.** Если парсинг был прерван (Ctrl+C / timeout), перед перезапуском удалить stale WAL: `rm -f nukus.db-wal nukus.db-shm`.
13. **Баг цикла парсера (починен 16.07.2026).** `_fetch()` и весь блок парсинга были **вне** цикла `for page` — загружалась и парсилась только **последняя** страница из max_pages. Цикл только логировал. Признак: в логах все "page N/5" появляются в одну миллисекунду, а HTTP GET — только один. Фикс: переместить `html = await self._fetch(url)` и весь код обработки внутрь цикла `for page`.
14. **Фильтр `_is_rental()` убивает категорию "rent" (починен).** Парсер намеренно пропускал все объявления с ключевыми словами "аренд", "сдам", "ижара" в заголовке. Для категории "rent" это вырезало 100% объявлений. Фикс: пропускать фильтр для `cat_name not in ("houses", "apartments")`.
15. **Фильтр цены `< 10 млн` убивает аренду (починен).** Парсер пропускал все объявления с ценой меньше 10 млн сум как "вероятную аренду". Для категории "rent" это вырезало все объявления (1-5 млн). Фикс: применять фильтр только для категорий продажи.
16. **Ползунок цены в HTML-отчёте не показывал аренду (починен).** `min=50` (млн сум), аренда стоит 1-5 млн. Весь slider был ниже минимального значения. Фикс: `min=0`.
17. **Мёртвые объявления на OLX.** OLX не убирает проданные/неактуальные объявления — они висят неделями. Продавцы часто не отвечают. Парсер не может это отфильтровать. Единственный индикатор — `days_online` (чем больше, тем вероятнее мусор). При жалобе пользователя сказать: «парсер показывает то что на сайте, мёртвые объявления — проблема OLX».
