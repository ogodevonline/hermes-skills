# Uzbek Bank Rates

Курсы валют в обменных пунктах банков Узбекистана через агрегатор bank.uz.

Использовать вместо `rates` (ЦБ РФ), когда пользователь в Узбекистане.

---

## Процесс сбора

1. Открыть `https://bank.uz/currency` через `browser_navigate`
2. Из верхней панели взять **Курс ЦБ Узбекистана** — табы USD/RUB/EUR/GBP/KZT с ценой и изменением
3. Из секции **«Лучшие курсы обмена валют в обменных пунктах»** — переключить вкладки на нужную валюту
4. Получить полный текст страницы: `browser_console(expression="document.body.innerText")`
5. Распарсить из текста: для каждой валюты топ-3 по покупке и топ-3 по продаже
6. Если browser_vision работает (модель с vision) — можно использовать для чтения таблиц

## Формат вывода

**Курс ЦБ Узбекистана:**
| Валюта | Курс |
| USD | 12 101 (+53) |
| RUB | 153 (+0.87) |
...

**USD**
| | Банк | Курс |
| Покупка | Universal bank | 12 020 |
| Продажа | Asakabank | 12 040 |

**RUB**
| | Банк | Курс |
| Покупка | Kapitalbank | 133 🔥 |
| Продажа | Ipak Yuli | 149 |

## Особенности пользователя

- Пользователь в **Нукусе**, его основной банк — **Kapitalbank**
- Подсвечивать курс Kapitalbank маркером `⬅️` и сравнивать с лидерами
- Если Kapitalbank лидирует — отмечать `🔥`

## Дополнительные данные на странице

- **Курсы денежных переводов** (РФ→Узбекистан): Avosend/Paysend, Yubor — показывать отдельно
- **Курсы криптовалют**: TON, BTC, ETH в сумах и долларах

## Триггеры

- Пользователь спрашивает «курс валют», «хорошая ставка», «где менять», «курс в банках»
- Пользователь в Узбекистане (Нукус) — всегда bank.uz, не cbr.ru
- Команда `/rates` — уточнить источник или использовать bank.uz по умолчанию для этого пользователя
