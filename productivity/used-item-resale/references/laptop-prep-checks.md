# Ноутбук: проверки и подготовка к продаже (Linux на ноуте)

## Батарея (без sudo)
```
upower -i $(upower -e | grep BAT) | grep -E "energy-full|capacity"
cat /sys/class/power_supply/BAT*/cycle_count
# запасной: cat /sys/class/power_supply/BAT*/energy_full /sys/class/power_supply/BAT*/energy_full_design  (мкВт·ч)
```
Износ = energy_full / energy_full_design; покажи расчёт. Ориентир (оценка): >80% — норма и плюс в объявлении; 70–80% — указать и заложить торг; <70% — скидка или замена. Циклы — интенсивность использования, не износ. «Батарея села» часто = лимит заряда 60/80% (ASUS Battery Health Charging) или слабое энергосбережение в Linux.

## OEM-ключ Windows в прошивке
```
sudo strings /sys/firmware/acpi/tables/MSDM
```
Есть строка `XXXXX-XXXXX-XXXXX-XXXXX-XXXXX` → чистая Windows активируется сама, редакцию установщик выберет по ключу. Пусто → в объявлении «без ОС». Пароль sudo не запрашивать.

## Температуры (нужна ли чистка/паста)
```
sudo apt install lm-sensors stress-ng -y
watch -n 2 sensors              # окно 1: Package id 0 / coretemp
stress-ng --cpu 0 --timeout 120 # окно 2
```
Ориентир (оценка): до ~90 °C без троттлинга — хватит продувки; ~100 °C и падение частот — чистка + паста. Тот же тест после сервиса = проверка качества работы.

## Риски самостоятельной замены пасты
Отключить батарею от платы первым делом (короткое); аккуратно со шлейфами; винты радиатора — по нумерам (перекос ухудшает контакт); пасты с горошину; если под радиатором жидкий металл (серебристая жидкость) — не трогать, собрать обратно. Для дорогих ультрабуков рекомендуй сервис; продувку со снятой крышкой (без снятия радиатора) можно самому.

## Установка Windows с флешки из Linux (Ventoy)
1. ISO: microsoft.com/software-download/windows11 → «Образ диска (ISO) x64», русский (из РФ может потребоваться VPN). Только официальный ISO.
2. Ventoy: `ventoy-*-linux.tar.gz` с github.com/ventoy/Ventoy/releases; `lsblk -o NAME,SIZE,TRAN,MODEL` — флешка = TRAN `usb` (sdX), **не nvme0n1**; `sudo sh Ventoy2Disk.sh -i /dev/sdX` (стирает флешку); перевставить и скопировать ISO.
3. ASUS: Esc при включении = меню загрузки (F2 = BIOS). В установщике удалить все разделы (старая ОС) → незанятое пространство. Сначала бэкап данных.
4. После: Windows Update (подтянет драйверы), при нехватке — сайт ASUS по коду модели; «Активация» = Активирована; перед продажей — сброс «Удалить всё».
