# Лид-машина для стоматологий Нукуса — выбранный путь (02.09.2026)

## Продукт (позиционирование по поправке Василия)
НЕ «продажа викторин». **Лид-машина = лид-платформа (lead-platform) как система лидогенерации под ключ**: человек видит рекламу/пост → проходит тест-воронку → видит услуги и цены → оставляет контакт одним селектором → заявка в личном кабинете клиента.

Пакет для клиента:
- Ядро: подписка на платформу (тарифы Lite $39/Pro $59/Business $99 — для Нукуса адаптировать вниз в сумах или модель «за лид»)
- Модуль: викторина-воронка под нишу клиента
- Придача: реклама (таргет) / контент-ведение — отдельно, маржа
- Разово: настройка под клинику

## Почему ниша — стоматология Нукуса (пилот, ОДИН)
- Василий лично в теме (7 имплантов + костная пластика) — контент не картонный
- Жена в Нукусе = локальные руки: переговоры, фото, внедрение
- Стоматология платит за записи (лид = приём = деньги), понимает ценность
- Низкая конкуренция по контенту в Нукусе; клиники уже заводят сайты (Sorriso, dr-askar, Innova) — гонка за пациентами идёт
