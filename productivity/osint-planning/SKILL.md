# OSINT Planning

Генератор плана работ для 30bit.ru. Вычисляет дедлайны, распределяет задачи по дням, печатает план в консоль.

## Запуск

```bash
cd ~/.hermes/skills/productivity/osint-planning/scripts
python3 planning.py
```

Выводит JSON-план с разбивкой по дням.
