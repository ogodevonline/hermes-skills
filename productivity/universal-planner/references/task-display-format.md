# Task Display Format — единый формат задач

> Источник: этот файл заменяет skill `task-display`, архивный с 2026-05-14.
> Скрипт: `~/.hermes/scripts/task_display.py`

Стандартный формат вывода задач для всех брифингов и прямых ответов пользователю.
Вместо сырого вывода трекера/Google API (который бесит пользователя).

## Формат

```
**H**
- `83` 💪 Зал, спину беречь *(📁 health · 🔄 4)*
- `103` 🚀 Доделать проект на 30bit *(📁 30bit)*

**M**
- `95` 🍎 Фрукты Лиме *(📁 lima · 🔄 2)*
- `35` 📝 English-lesson *(⚠️ 9 переносов)*
- `82` 🛁 Постирать полотенце *(📁 home)*
```

### Правила (строгие):
- **Группировка по приоритету:** `**H**` → `**M**` → `**L**`
- **Каждая задача:** `- \`ID\` Имя задачи`
- **Доп.инфа** в скобках после имени через ` · ` (точка-пробел)
  - `📁 category` — если есть категория/проект
  - `🔄 N` — если переносов 2-4
  - `⚠️ N переносов` — если переносов 5+
  - `срок MM-DD` — если не сегодня
  - `⏱1.5ч` — если есть длительность
- **Не выводить:** сырой вывод API/БД, теги (raw), даты в ISO-формате

> ⚠️ Источник — Google Tasks: полей `category`/`carry_over`/`duration` в нём нет.
> На практике из доп.инфо остаётся `срок`; приоритет — по маркеру ❗ в заголовке
> (❗ → H, иначе M). Счётчик переносов (🔄/⚠️) больше не показывается.

## Использование скрипта

```bash
# Все задачи на сегодня
python3 ~/.hermes/scripts/task_display.py

# Конкретные ID
python3 ~/.hermes/scripts/task_display.py --ids 83,95
```

Скрипт читает Google Tasks (списки TODAY/BACKLOG через `tasks_api.py`),
группирует по приоритету, форматирует по правилам выше. Числовой ID берётся
из notes задачи (`local:#228`), иначе — первые 8 символов Google-ID.

## Где применяется

| Место | Как |
|-------|-----|
| Ответ пользователю "что по задачам" | Вручную, через `task_display.py` или по правилам формата |
| Вечерний бриф | `evening-diary-brief` — компактный список задач |
| Утренний ритуал | `morning-ritual` — топ-3 + остаток |
| Утренний бриф (скрипт) | `morning-brief-pipeline/tasks.py` — вызывает `task_display.py` |
| Планирование | `life-planning` — ссылается на этот формат |
| Universal Planner | При создании задач через `tasks_api.py` — форматировать по этому стандарту |

## Pitfalls

1. **Сырой вывод трекера/API никогда не показывать пользователю** — он содержит лишние детали (даты, время, теги) в нечитаемом виде
2. **ID сохранять** — показывать числовой ID из notes (`local:#N`); для действий с задачей — Google-ID через `tasks_api.py`
3. **Выполненные задачи скрыты** — фильтр `not l.startswith("✅")` в скриптах брифа
