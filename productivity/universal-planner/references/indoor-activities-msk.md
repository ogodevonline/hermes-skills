# Indoor-активности Москва (для пар, бюджет до 4000₽)

Быстрая справочная таблица. Цены — на двоих, если не указано иное.

## Типовые варианты

| Активность | Цена (на двоих) | Комментарий |
|---|---|---|
| 🍿 **Кино** | 800-1200₽ | Билеты ~400-600₽/чел. + фудкорт ~1000-1500₽ = до 2700₽ |
| 🎤 **Стендап** | от 1900₽ | Билеты от 950₽/чел. Есть на Трубной, есть по 1190₽ с джазом |
| 🔍 **Квест** | 1500-2500₽ | 1 час. Недорогие есть на ВДНХ/Проспект Мира |
| 🎲 **Антикафе** | 600-1500₽ | ~300-500₽/час с чел. Чай/кофе входит. Настолки, PS |
| 🎱 **Бильярд/теннис** | 1000-1600₽ | ~500-800₽/час |
| 🖼️ **Музей (не бесплатный)** | 600-1200₽ | ММОМА, Музей Москвы, МАММ ~300-600₽/чел |
| 🎪 **ТЦ/фудкорт** | 1000-2000₽ | Просто погулять + поесть |
| 🧠 **Квиз-викторина** | 0-1000₽ | Бывают бесплатные, бывают ~500₽/чел |

## Близость к Бабушкинской (оранжевая ветка)

| Место | Время от Бабушкинской | Комментарий |
|---|---|---|
| ВДНХ | ~5-7 мин (3 станции) | Музей героизма, павильоны, фонтаны |
| Сокольники | ~10-12 мин (автобус/метро) | Парк, природа |
| Проспект Мира/Рижская | ~15 мин | Квесты, антикафе, кафе |
| Центр (Китай-город) | ~25-30 мин | Зарядье, музеи, стендап |
| ТЦ "Золотой Вавилон" | ~5 мин пешком | Кино, фудкорт, магазины |

## Когда погода плохая

Приоритет indoor-вариантов при дожде/холоде:
1. **Рядом с домом** (Бабушкинская): ТЦ "Золотой Вавилон" (кино+еда)
2. **Близко** (ВДНХ): Музей героизма, павильоны, "Буран"
3. **Центр** (если есть желание ехать): стендап, квест, антикафе

## Бесплатные варианты на май 2026

- Московская музейная неделя 11-17 мая (разные музеи по дням)
- Музей героизма на ВДНХ — бесплатные экскурсии 9-11 мая
- Старый Английский двор в Зарядье — бесплатно 11 мая (пн)
