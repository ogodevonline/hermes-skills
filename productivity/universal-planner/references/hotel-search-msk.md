# Подбор отеля в Москве (пара, бассейн/зал/сауна)

## Процедура
1. Критерии спроси или возьми из контекста: удобства (у Василия стандарт — бассейн + спортзал + сауна, уровень не ниже AZIMUT Олимпик 4★), даты, аэропорт/вокзал прибытия.
2. Кандидаты: `web_search` «отели Москвы 4 звезды с бассейном сауной фитнес…» + 101hotels `4stars_pool`. Лучший источник реальных цен — выдача Островка с фильтрами, которую присылает сам пользователь (см. «Чтение выдачи Островка»).
3. **По каждому кандидату проверь на официальном сайте (или accor.ru / radissonhotels):** входит ли СПА/фитнес в проживание, часы, нужна ли запись. Агрегаторы пишут «есть бассейн» и там, где он платный (пример: Cosmos ВДНХ — абонемент 1500 ₽/4 ч для гостей), и не упоминают правила записи (AZIMUT Олимпик: клуб — за сутки, бассейн — за 3 ч, клуб сторонний). Ищи фразы «для проживающих бесплатно / включено в стоимость».
4. Логистика прибытия: сопоставь аэропорт с отелем (Внуково → поезд ЦППК на Киевский вокзал 33 мин, 350 ₽, ~раз в час 07:00–23:00; Аэроэкспресса во Внуково НЕТ с 08.2024 — отели у Киевской выигрывают), час заезда vs время прилёта, стоимость раннего заезда (обычно +50% суток) и бесплатная камера хранения.
5. Выдача: 3–4 варианта списком (цена за всё время + ≈за ночь, рейтинг/число отзывов, удобства + бесплатно ли, метро, плюс/минус), в конце выбор по сценарию: «вау / центр-баланс / большой бассейн / дешевле всего». Отели с платным СПА и далёкие (за МКАД, у аэропортов) — одной строкой «отсеял».
6. **Сразу давай ссылки на Островок с датами** (пользователь бронирует там и просит их):
   `https://ostrovok.ru/hotel/russia/moscow/mid<ID>/<slug>/?dates=DD.MM.YYYY-DD.MM.YYYY&guests=2`
   `mid` и slug бери из выдачи `web_search "ostrovok.ru <название отеля>"`.
7. Сравнивая цены из выдачи, смотри тип номера: Островок показывает самый дешёвый вариант, это бывает twin или номер для маломобильных — помечай, цена на двуспальную может отличаться.
8. На «это всё?» — честно: разобрана первая страница (~20 из N), предложи следующую.

## Чтение выдачи Островка (цены на даты)
Страница поиска и карточки рисуются JS — `web_extract`/`web-tools extract` отдают только «Ищем варианты». Работает реальный браузер:
1. Если `browser_exec` не видит CDP на 127.0.0.1:9222 — подними headless Chromium из Playwright-кэша фоновым процессом: `terminal(background=true)` с `~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome --headless=new --no-sandbox --remote-debugging-port=9222 --user-data-dir=<scratch>/chrome-prof --lang=ru-RU about:blank` (без nohup — терминал его отклоняет).
2. `browser_exec`: `new_tab(<ссылка пользователя>)`, `wait_for_load()`, `sleep ~12 с`, прокрутка, `js("document.body.innerText")` → записать в файл в `os.environ['BH_AGENT_WORKSPACE']` (переменной `workspace` внутри кода нет).
3. Читать файл через `read_file` с offset, а не печатать целиком. В тексте на каждый отель: название, адрес, метро, оценка/отзывы, тип номера, «X ₽ за N ночей для 2 гостей» (и меньшая цена «войдите и забронируйте»).
