# Афиша на ближайшие выходные в Москве — рабочий рецепт

Для запросов «куда сходить завтра/на выходных (с братом/сестрой/друзьями)». Быстро, без долгого диалога: сначала выдать варианты, уточняющий вопрос — в конце.

## Порядок

1. `TZ=Europe/Moscow date` → вычислить конкретные даты (сб/вс). Все запросы — с датами.
2. Погода — детерминированно, без поиска (Open-Meteo, без ключа):
   ```
   curl -s "https://api.open-meteo.com/v1/forecast?latitude=55.75&longitude=37.62&daily=temperature_2m_max,temperature_2m_min,precipitation_sum,precipitation_probability_max,weathercode,windspeed_10m_max&timezone=Europe/Moscow&start_date=YYYY-MM-DD&end_date=YYYY-MM-DD"
   ```
   weathercode 71-77 = снег, 61-67 = дождь, 3 = пасмурно. Сказать, какой день лучше для прогулки.
3. Афиша — 1-2 запроса вида `куда сходить в Москве в выходные 7 и 8 ноября 2026`. Выдача отдаёт свежие дайджесты с датами/адресами/ценами: vedomosti.ru/gorod, thecity.m24.ru, gorbilet.ru/blog, vm.ru, moscowwalks.ru, moscowpass.com (недельная афиша на 50 событий), mos.ru (события в парках). Сниппетов обычно хватает — extract не нужен.
4. Если спросят «а платное?» — один запрос `Москва <даты> афиша семейные спектакли иммерсивные шоу выставки билеты`. Сезонное (катки, ярмарки) — отдельным запросом и явно сказать, если ещё не открылось.

## Уточнения идут цепочкой — каждое = новый узкий поиск

Типичная цепочка: бесплатно → платно → «необычное» → «квесты с актёрами» → «без хоррора, много людей» → «просто прогулка + кафе». На каждое уточнение — 1-2 целевых запроса и готовый список, не пересказ прошлого ответа. Узнал возраст/диету/состав компании — сразу пересобрать под них (взрослым убрать детские спектакли, добавить 18+).

## Вечер на конкретную дату — полный прочёс

Когда нужно «что-то интересное на вечер DD месяца» и первые идеи отвергнуты — прогнать ВСЕ форматы параллельными запросами с датой в тексте, потом свести:
- **Агрегаторы по дню**: `msk.kassir.ru` (страницы категорий/афиши показывают события с датами и «от» ценой), `bileti.ru` (театры/мюзиклы на дату), `afisha.org.ru/<событие>-moskva-DD-MM-YYYY`, `concert.moscow`, Time Out «Куда сходить с X по Y» (недельный дайджест), RUSSPASS «Афиша на <месяц>».
- **Концерты на площадках**: страница площадки на live.mts.ru (МТС Live Холл, теплоходы и т.п.) и сайт площадки — официальная дата важнее агрегатора (kassir может показывать лишний день).
- **Ужин + шоу**: гастрошоу в «Метелице» (Новый Арбат) — ужин-сет добавляется ТОЛЬКО при покупке билета (на месте в ~3 раза дороже), дресс-код вечерний, 3 ч с антрактами; иммерсивный детектив на теплоходе River Palace (причал «Нац. центр Россия», только по своим датам).
- **Речной ужин**: причал «Киевский» (Бережковская наб., напротив пл. Евразии — у Рэдиссон Славянской) — rivertickets.ru / mosflot.ru; круглый год ходят флотилия «Рэдиссон Ройал» и Erwin.Река (причал «Гостиница Украина»). Ноябрьские рейсы отдельных теплоходов не гарантированы — проверять конкретную дату.
- **Стендап**: standupclub.ru (состав «на этой неделе» — без даты, предупреждать), Coin Event Hall (сольники).
- **Иммерсив с актёрами**: claustrophobia.com показывает расписание сеансов «Москва-2048» на месяц; сверить с msk2048.ru.
- **Live Арена — это за МКАД** (Новоивановское, МЦД-1 «Сколково», метро нет; на выходе 11 тыс. человек и один выезд) — всегда предупреждать и давать дорогу.

## Длинная прогулка в холод

Когда хотят «хорошо пройтись, но не замёрзнуть»:
- День — самый тёплый и сухой из прогноза; старт около 12:00, финиш до заката (в ноябре темнеет ~16:30).
- Маршрут 4-6 км с тёплой точкой каждые 1,5-2,5 км (≤25-30 мин на улице подряд): бесплатный музей/ДК на старте (место встречи), маркет/кафе в середине, веганское кафе на финише.
- Расстояния — по координатам Nominatim (`nominatim.openstreetmap.org/search?q=...&format=json`, User-Agent обязателен, пауза 1 c) + пеший OSRM `routing.openstreetmap.de/routed-foot/route/v1/foot/lon,lat;lon,lat`. Если роутинг не прошёл — давать прямые расстояния ×1.2 и честно помечать «примерно».
- Проверенный центр-маршрут (~5 км): ГЭС-2 → Патриарший мост → ХХС → Гоголевский/Никитский б-р → Тверской б-р («Дом вкуса», маркет) → Патриаршие → «Циники». Укоротить: от «Дома вкуса» сразу в «Циники» (5 мин).
- Альтернатива без Патриарших (~5 км): ГЭС-2 → Большой Москворецкий мост → Зарядье → Варварка → Ивановская горка (Хохловский/Петроверигский) → Покровский б-р (КОМ) → Винзавод («Открытые студии», бесплатно) → Artplay (маркет + «Мох»). Укоротить: старт с Зарядья (~3,5 км).
- Если место «надоело» — менять весь район, а не одну точку.
- Под маршрут подбирать события того же района на тот же день (экскурсия с гидом 14:00, маркет как тёплая точка, концерт при свечах в середине, камерный концерт вечером) — подавать как 2-3 связки «район: прогулка → событие → веганский ужин».
- Советы одной строкой: термос, непромокаемая обувь (после снега слякоть).

## Формат ответа

- Группы: «рядом с домом (Бабушкинская/ВДНХ)», «бесплатно», «платно» (шоу / театр / выставки и мастер-классы / спорт).
- Каждый пункт: что, где (метро), когда, цена, возрастная метка, источник-домен.
