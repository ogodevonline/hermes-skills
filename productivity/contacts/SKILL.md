# Contacts

Система хранения контактов в Obsidian. База лежит в `~/hermes-vault/контакты/`.

Структура:
```
контакты/
├── _index.md              # список групп + людей
├── groups/
│   ├── семья.md
│   └── работа.md          # пока пусто
└── people/
    ├── оля-мама.md
    ├── александр-папа.md
    ├── олег-брат.md
    ├── света-сестра.md
    └── ...
```

## Команды

- **`/contacts`** — показать все группы и людей
- **`/contacts группа семья`** — показать группу + всех её участников + факты
- **`/contacts имя`** — показать факты о конкретном человеке
- **`/contacts имя факт`** — добавить факт о человеке
- **`/contacts группа группа_название`** — показать или создать группу

## Перед отправкой сообщения

Когда пользователь просит написать кому-то («напиши маме», «напиши брату»):

1. Загрузить файл человека из `people/{имя}.md`
2. Посмотреть факты и последние контакты
3. Только после этого составлять сообщение
4. Не выдумывать факты — только то, что в файле

## Формат файла человека

```markdown
---
groups: [семья]
---
# Имя (роль)

**Роль:** мама/папа/брат/...
**Профессия:** ...
**Имя:** ...

## Факты
- факт 1
- факт 2

## Последние контакты
- 2026-06-03: написать, спросить как дела
```

## Формат файла группы

```markdown
# Название группы

Участники: имя-1, имя-2

## Контакты (факты по группе)
- ...
```

## Добавление контактов

При добавлении нового человека:
1. Создать файл в `people/{имя}.md`
2. Добавить `--- groups: [...] ---` с группами
3. Если группы нет — создать в `groups/{группа}.md`
4. Обновить `_index.md`
