# Ranobe / Web Novel Offline Download

## Trigger

- Пользователь просит найти/скачать ранобэ, китайскую новеллу, веб-новеллу ИЛИ обычную книгу (исторический роман, booktok-подборку, любую художественную) для оффлайн чтения
- Список книг с русскими и английскими названиями + «найди и скачай» — тоже сюда (см. раздел «Поиск обычных книг»)
- В запросе есть название (часто на русском) + «скачать», «оффлайн», «txt», «epub», «читать», «fb2»
- ⚠️ НЕ сюда: «найди новеллу, которую я смогу читать на АНГЛИЙСКОМ» (изучение языка, проверка уровня) — это english skill → `references/chinese-novels-english.md` (подбор по сложности + протокол уровень-теста).

## Workflow

### 1. Найти новеллу
```bash
~/.cargo/bin/web-tools search "<название> китайская новелла" --source yandex --count 20
```
- Русские названия лучше ищет Яндекс (`--source yandex`).
- Одна новелла живёт под несколькими именами — собери все: русский перевод, английское название, китайский оригинал. Пример: «Слава Королю» = Hail the King = 国王万岁 = Mad Blade During Troubled Times.
- Локальный поиск (hms/gms) — почти всегда пусто по новеллам, сразу идти в веб.

### 2. Искать сайты с готовыми файлами (а не онлайновые читалки)
```bash
~/.cargo/bin/web-tools search "<название> скачать txt epub" --source yandex --count 15
```
Приоритет: сайты с **прямыми ссылками на файлы** (TXT/EPUB/FB2/DOCX). Онлайновые читалки (jaomix, ranobelib, ranobes) требуют парсинга каждой главы — это запасной вариант.

### 3. Источники (проверено 07.2026)
| Сайт | Что даёт | Статус |
|------|----------|--------|
| **loghorizont.ru** | Готовые файлы TXT/DOCX/FB2/EPUB, разбитые на части (обычно 1-500, 501-1000, 1001-N). TXT/FB2 — в .zip | ✅ лучший |
| **jaomix.ru** | Все главы онлайн (URL на каждую главу) | ⚠️ нет прямых ссылок на скачивание |
| **novelgo.org** | — | ❌ HTTP 403 |
| wuxiaworld.ru, ranobe.me | «Скачать» → боты/партнёры, не прямые файлы | ⚠️ обходить |

URL-паттерн loghorizont: `https://loghorizont.ru/ranobe/{Slug}-/{Name}_{from}_{to}.{ext}` — точный формат и рабочий пример см. `references/loghorizont-pattern.md`.

### 4. Скачать все части
```bash
curl -sL -o "part.txt.zip" "URL" -A "Mozilla/5.0" --max-time 120
```
Проверить, что скачалось не HTML: `file *.epub *.zip` — должно быть `EPUB document` / `Zip archive`.

### 5. Собрать и проверить
```bash
unzip -o -q "part.txt.zip" -d "part_N"
cat part_1/*.txt part_2/*.txt part_3/*.txt > FULL.txt
grep -c "^Глава" FULL.txt   # должно сойтись с заявленным числом глав
```

### 6. Очистить мусор (обязательно!)
Файлы от loghorizont содержат вставки, которые надо вычистить перед отправкой:
- **Рекламные блоки между частями** («Друзья, если Вам понравилась книга… Поддержите Нас…») — regex-удаление
- **Заголовки частей** («Ранобэ: <name> / Описание: / Кол-во глав: N-M»)
- **Футеры в конце каждой главы** (например «Отблагодаритьте нашу команду: …» — может быть 1300+ повторений): `sed -i '/.../d'`
- Нормализация строк: `\r\n → \n`, схлопнуть 3+ пустых строк

Готовые сниппеты: `references/loghorizont-pattern.md`.

### 7. Доставка в Telegram
Загрузить `telegram-file-delivery` ПЕРЕД отправкой. **НЕ через MEDIA**:
- TXT — прямой Telegram Bot API `sendDocument` (MEDIA пришлёт как текст — пользователь бесится)
- EPUB — тоже `sendDocument` с `application/epub+zip` (MEDIA работает только для картинок/аудио/видео)
- Проверять `status_code == 200` и `ok == true`
- Таймаут ≥120с для больших файлов (19 МБ TXT — ок, лимит Telegram 50 МБ)

## Поиск обычных книг (не ранобэ)

Художественная литература (исторические романы, booktok-подборки) — та же цепочка «найти → скачать → проверить → отправить», но другие источники:

1. **Сразу уточнить язык.** Если пользователь не сказал — сначала проверить русские переводы, английские качать по запросу («на английском тоже скинь»). Пользователь (Василий) ждёт обе версии, если просит.
2. **Свежие западные книги (2023–2025) почти никогда не переведены** — Флибуста/Libgen пусто. Не искать бесконечно: сказать честно + предложить аналог (переведённая серия того же автора, та же эпоха/жанр). Пример: The Gilded Heiress (2025) не переведена → аналог «Охота на наследницу» Джоанны Шуп (эротический роман, Gilded Age, есть fb2).
3. **Флибуста OPDS** — основной источник русских версий. ОБЯЗАТЕЛЬНО `searchType=books` в URL, иначе пустой результат.
4. **Libgen.li** — английские и русские книги. Скачивание: `ads.php?md5=` → вытащить `get.php?md5=...&key=...` → качать с ключом.
5. **archive.org** — книги в общественном достоянии (эпик-старые, до 1928).

Полный справочник команд, статусов зеркал и питфоллов: `references/ebook-libraries.md`.

## Pitfalls

- **Части EPUB нельзя склеить через `cat`** — это zip-контейнеры со своими манифестами. Отдавать частями (1-500, 501-1000, 1001-N) или перепаковывать отдельно.
- **Рекламные вставки остаются в СЕРЕДИНЕ собранного файла** (после каждой 500-й главы) — после чистки обязательно перепроверить `grep`.
- **Проверять `file` после скачивания** — 403/404 сайты отдают HTML вместо файла.
- Число глав в grep может превысить ожидание (включает «Глава N. Название» из оглавления) — главное, чтобы сходился порядок величин и не было разрывов нумерации.
- После чистки `wc -c` показывает байты UTF-8 (кириллица = 2 байта/символ) — 10.6М символов ≈ 19М байт, это нормально.
- **Пользователь просит «скинь файлы» повторно → просто переотправить** (проверить существование на диске, вызвать sendDocument заново). Файлы могли «уйти» (API вернул 200), но пользователь не увидел — не спорить «я уже отправлял», а переотправить молча. Проверять `file`/`ls` перед каждым ре-отправом.
- **«Скинь хотя бы что нашёл»** — отдавать частичный результат сразу (скачанное + краткое описание + статус остальных), не дорабатывать молча весь список: пользователь нетерпелив.
- **Имя файла с пробелами ломает `curl -F document=@...`** — перед отправкой скопировать в имя с подчёркиваниями (`cp "Автор Название (2018).fb2" "Автор_Название.fb2"`).
