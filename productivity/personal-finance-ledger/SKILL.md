# Personal Finance Ledger

Локальный учёт личных расходов Василия вместо ZenMoney. Источник данных — выписки
Сбера (PDF/Excel), хранилище — SQLite на сервере, интерфейс — чат: реплика
«кофе 250» или брошенный документ. Навык фиксирует принятое решение и план
реализации.

## When to Use

- Василий кидает выписку/справку из Сбера — разложить транзакции по категориям
- Вопросы «куда ушли деньги», бюджеты по категориям, графики расходов
- Отметка расходов репликами в чат («такси 800 с карты», «зарплата 180к»)
- Обсуждение «зачем/не зачем ZenMoney», выбор финансового инструмента

## Контекст решения (зафиксировано 21.09.2026)

ZenMoney abandoned: автоимпорты из Сбера не работают, ручной ввод неудобен,
привычка «Подбить расходы в ZenMoney 18:30» мертва с июня. ZenMoney без
автоимпорта = мёртвый посредник: приложение даёт только ручной ввод + отчёты,
а это делает чат лучше. Направление — СВОЙ локальный ledger (решение принято,
реализация НЕ начата — проверь статус ниже, прежде чем строить заново).

## Архитектура

1. **Хранилище**: SQLite `~/.hermes/ledger/ledger.db` (философия как у трекера:
   одна БД, CLI, MSK через zoneinfo). Таблицы: transactions (date, amount_kopecks,
   currency, direction, account, category, payee, comment, source='statement|chat',
   stmt_hash), categories, merchants (выученный маппинг контрагент→категория),
   budgets(category, month, amount).
2. **Импорт выписок Сбера**: СберОнлайн → «Справки и документы» → выписка за
   месяц → PDF или Excel. Парсер писать под РЕАЛЬНЫЙ формат файла (первый файл =
   фикстура), не вслепую. Дедуп по хэшу строки выписки — перекрывающиеся выписки
   (1–15 и 1–30) не задваивают.
3. **Категоризация**: маппинг по контрагенту («Пятёрочка»→продукты); правка
   пользователя в чат запоминается в merchants, следующая выписка раскладывается
   сама.
4. **Ручной ввод репликами**: «кофе 250» / «такси 800 с карты» прямо в чате.
5. **Планы/бюджеты** (аналог «планов» ZenMoney): budgets по категориям на месяц,
   прогресс — в вечернем брифе.
6. **Графики**: matplotlib → PNG в Telegram (круговая «куда ушло», дневная
   линия, прогресс-бары бюджетов). ⚠️ matplotlib/pandas на сервере НЕ
   установлены — ставить (uv/venv) перед первым рендером.
7. **Автоимпорт-обходняк**: Сбер шлёт выписки на e-mail; Gmail подключён
   (google-workspace, аккаунт svaaugust) — месячный cron: найти PDF выписки →
   распарсить → разложить → сводка в чат с подтверждением новых контрагентов.

## Готовые навыки в хабе (проверено 21.09.2026 — не отвечать «готового нет»)

Перед написанием своего — `hermes skills search` / grep по
`~/.hermes/skills/.hub/index-cache/hermes-index.json`. Кандидаты:

| Навык | Что даёт | Минус для нашего случая |
|---|---|---|
| Personal Finance Reconciler (`financial-reconciler`) | локальный SQLite, импорт банковских выписок, автокатегории, бюджеты, NL-запросы | форматы CSV/OFX/QFX западных банков; парсер под Сбер всё равно писать |
| Personal Finance Tracker (`spotsccc-finance`) | CRUD сделок, отчёты | требует свой PostgreSQL-сервис с CLI — лишний рантайм |
| Beancount / Personal Finance Beancount | plain-text бухгалтерия + Fava-графики | двойная запись = лишняя бюрократия для быта |
| YNAB / Ynab Api | бюджет-менеджмент через API | внешний сервис, не решает проблему «нет автоимпорта Сбера» |

Trust level `community` + финансовый доступ = аудит исходников после установки,
ДО записи данных. Предпросмотр: `hermes skills inspect "<Display Name>"` —
аргументом работает display name, голый identifier даёт «No exact match».

## Procedure — приём выписки (после реализации ledger)

1. Файл от пользователя (PDF/Excel/скрин). PDF → навыки `pdf` / `ocr-and-documents`,
   Excel → `xlsx`.
2. Распарсить строки → INSERT с stmt_hash-дедупом → нераспознанных контрагентов
   показать списком на разовое подтверждение категорий.
3. Отдать сводку: итог, топ-категории, отклонения от бюджета; график PNG по
   запросу или в вечернем брифе.

## Pitfalls

- **Не строить парсер до получения реальной выписки** — формат Сбера меняется,
  слепые regex горят.
- **Дедуп обязателен**: перекрывающиеся выписки — норм, а не исключение.
- **Суммы**: Сбер печатает «−1 234,56 ₽» с NBSP/узким пробелом — нормализовать
  перед парсингом; хранить копейки int.
- **Смешанные валюты** (RUB/UZS) — поле currency обязательно.
- Сырой дамп БД в чат не показывать — только форматированную сводку (тот же
  стандарт, что у personal-task-tracker).
