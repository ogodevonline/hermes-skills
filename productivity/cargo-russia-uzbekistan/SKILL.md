# Карго и посылки Россия → Узбекистан

Класс задач: «как отправить X из Москвы в Нукус/Ташкент». Актуально для Лимы (материалы для афрокос из Москвы) и личных посылок. Данные собраны 15.09.2026 через `web-tools search` — цены и живность офисов проверяй заново перед рекомендацией.

## When to Use

- Пользователь спрашивает как/сколько стоит отправить посылку, груз, закупку из РФ в Узбекистан.
- Нужно оценить, можно ли вообще везти конкретный товар через границу (лекарства, жидкости, аэрозоли).

## Сначала — ограничения по содержимому

1. Проверь состав товара на этанол/аэрозоль/скоропорт. Пример: **Канефрон Н капли = 16,0–19,5% этанола** (canephron.ru/instruction-kapli) → авиа-ограничения на жидкости, СДЭК такие тарифицирует наземкой.
2. Правила СДЭК (cdek-tk.ru/blog): медикаменты — только заводская упаковка + кассовый чек, опись вложений на русском+английском в накладной («Личные вещи» — плохо), жидкость для авиа ≤500 мл/ёмкость, аэрозоли в самолёт запрещены, ≤30 кг/место.
3. **Лайфхак: проверяй наличие товара в самом Узбекистане** — Bionorica продаёт Канефрон официально (canephron.uz), везти через таможню два флакона бессмысленно. Для любой позиции: `web-tools search "<товар> узбекистан купить аптека" --domain uz`.
4. Канекалон, синтетические пряди, текстиль, бытовая химия без спирта — обычные неограниченные грузы, везутся всем.

## Провайдеры (проверено поиском 15.09.2026)

- **СДЭК** — международная посылка РФ→UZ «от 890 ₽» (cdek.ru/ru/inter/uzbekistan/), ПВЗ в Нукусе (cdek.ru/ru/offices/nukus). ⚠️ часть офисов на Яндекс.Картах «больше не работает» — звонить до отправки. Сайт cdek.ru — JS, `web-tools extract` отдаёт пусто, брать данные из сниппетов поиска.
- **UZCARGOTRANS** — uzcargotrans.ru, Москва (Саларьево), посылки от 1 кг, от двери до двери, +7 (495) 201-38-21.
- **М-Карго** — сборные авиагрузы Москва→Нукус (m-cargo.ru).
- **UTG Express** — utg-express.ru, заявляет Москва→Нукус 1–2 дня от ~47–57 ₽/кг, но **минимум 25 кг оплачиваемого веса** — для мелких посылок невыгодно. ⚠️ Сайт шаблонный (называет Нукус «городом в России») — цифры проверять звонком.
- **ТГ-карго и диаспора** — t.me/perevozkauzru, каналы «МОСКВА*ТАШКЕНТ», объявления Авито и OLX.uz по запросу «карго москва ташкент». Порядок ~300–600 ₽/кг из объявлений, НЕ проверено — запрашивать в ЛС цену за кг + плечо Ташкент→Нукус.
- **Почта России / EMS** — с Узбекистаном обмен работает; с 01.09.2026 изменены международные тарифы/правила (info.pochta.ru/support/no-mail-exchange), возможны задержки. Калькулятор: postprice.ru/international (JS-форма, extract не считает — только браузер).

## Procedure

1. Определить тип вложения → секция «ограничения» (этанол/аэрозоль/таможня).
2. Разовая мелкая посылка → СДЭК до ПВЗ Нукус (уточнить, что ПВЗ живой).
3. Регулярная закупка / тяжелее ~5 кг → карго (UZCARGOTRANS, ТГ-каналы): спросить цену за кг, срок, есть ли доставка до Нукуса или только Ташкент.
4. Дёшево и не срочно → Почта/EMS через postprice.
5. Перед «вот вариант» — live-проверка живости сервиса (pitfall #22 в web-search-scraper).

## Pitfalls

- Цены карго-компаний почти никогда не публичны — в сниппетах/на сайтах только «от». Реальную цену даёт только запрос в ЛС/звонок; так и пиши пользователю.
- Не смешивать «Ташкент» и «Нукус»: у многих карго финальное плечо до Нукуса отдельная услуга.
- Медикаменты на спирту + международная отправка = риск задержки таможней; всегда предлагать альтернативу «купить на месте».
- Канефрон ≠ канекалон: пользователь пишет «канеколон» в одном запросе с обоими — уточняй, лекарство или пряди для кос.

## см. также: известные баги в web-search-scraper (user-owned, чинить вручную)

- В разделе «Параметры CLI» таблица с `--query`/`--preview` — это флаги `search.py`, бинарник `web-tools` их отвергает: `web-tools search "..." --preview` → `error: unexpected argument '--preview' found` (проверено 15.09.2026). У бинарника запрос — позиционный, флаги: `--source --count --lr --domain --no-region --sortby --json`. Предложить пользователю поправить или `hermes curator adopt web-search-scraper`.
