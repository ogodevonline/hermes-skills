# README-First Knowledge Base — conventions

## Философия

README-first = **самое простое и самое рабочее**: markdown + README(index) + git, и всё.
Никаких сервисов, баз данных, эмбеддингов, вендоров. Source of truth = md, который человек
и AI читают напрямую в любом редакторе. Всё производное (поисковый индекс, HTML-карта,
граф связей) регенерируется из md — git остаётся чистым.

## Структура

```
AGENTS.md / CLAUDE.md      ← entry point для AI-ассистента
docs/
  README.md                ← мастер-индекс
  /services
    /<service>
      README.md            ← всегда индекс папки
```

Каждая папка = README.md как её индекс. README.md — всегда точка входа в папку.

## Онтология (опционально, для структурированных БЗ)

Заимствовано из [Palantir Ontology](https://www.palantir.com/docs/foundry/ontology/overview):

| Тип | Описание | Пример |
|---|---|---|
| **Entity** (сущность) | Субъект или объект реального мира | Пользователь, сервис, контракт |
| **Event** (событие) | Действие над сущностью в момент времени | Развёртывание, инцидент, решение |
| **Document** (документ) | Подтверждение сведений в унифицированном формате | Спецификация, ADR, runbook |

Оформляется через frontmatter в md:

```yaml
---
node_type: service  # entity | event | document
title: Auth Service
links:
  depends_on: [db-cluster]
  documented_by: [auth-adr]
---
```

`gitmark lint` проверяет инварианты (битые ссылки, сироты, папки без README, невалидный frontmatter).

## Правила для AI-ассистента при работе с KB

1. **Не редактировать [index].md вручную** — это ручной файл, обновляется человеком
2. **Не удалять frontmatter** — он нужен для онтологии и линтера
3. **Новые md → в соответствующую папку + обновить README папки**
4. **Ссылки — только относительные**, на md-файлы без расширения: `[Auth Service](../services/auth)`
5. **Если папка не имеет README — не создавать в ней файлы**, сначала спросить человека

## Примеры (из практики)

- **hub.neuraldeep.ru** — production проект, docs/ структурированы по сервисам, каждый сервис = отдельная папка с README.md
- **~/hermes-vault/** — Obsidian vault, README-first с 17 README на 23 папки

## Инструменты

- **gitmark** — CLI для индексации, поиска, карты и линтинга (проект пользователя)
- **hms** — поиск по ~/.hermes (системные файлы Hermes)
