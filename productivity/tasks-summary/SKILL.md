# Tasks Summary

Выводит активные (открытые) задачи из **Google Tasks** — списки `⛅ TODAY` и
`📥 BACKLOG`. Источник истины для задач с 06.10.2026 (локальная `tasks.db`
больше не используется).

Читает через `skills/productivity/google-workspace/scripts/tasks_api.py`
(`get_service()`, OAuth уже настроен — свой не пишем).

## Запуск

```bash
python3 ~/.hermes/skills/productivity/tasks-summary/scripts/tasks_summary.py
```

### «Что на сегодня» = задачи + Календарь дня

Вопрос про день («что у нас на сегодня», «что сегодня») — одним заходом: `TZ=Europe/Moscow date`, `tasks_summary.py` и события Календаря за сутки (workdir = scripts google-workspace):

```bash
python3 google_api.py --account svaaugust calendar list --start 2026-11-06T00:00:00+03:00 --end 2026-11-07T00:00:00+03:00 --max 30
```

Ответ: задачи, сгруппированные по срочности (горит до ближайшего события / 🔴 не горит / фон), затем только **оставшиеся** на сегодня события Календаря (прошедшие утренние привычки — одной строкой). Учитывай режим дня (зал Пн/Ср/Пт утром). В конце — один вопрос «что уже сделано?».

## Формат вывода

```
📋 Задачи:
1. 🔴 Срочная задача (❗ в заголовке Google = High)
2. Обычная задача дня
3. 📥 Задача из BACKLOG
...
```

- `🔴` — задача High (в Google заголовок начинается с `❗`);
- `📥` — задача из списка BACKLOG;
- без префикса — открытая задача из списка TODAY.

Если открытых задач нет — выводит `✅ Все задачи выполнены`.

## После показа: разбор списка

- Сверь каждую задачу с датой (`TZ=Europe/Moscow date`): если в заголовке окно/срок уже прошёл — спроси, актуальна ли, а не перечисляй молча.
- Подсвети, что срочнее всего относительно ближайших событий (например, до приезда/поездки неделя).
- Вывод — нумерованный список, без таблиц.

## Правка задач (когда пользователь даёт апдейты)

Пользователь обычно отвечает потоком: «это сделал, это переформулируй, завтра надо X». Сразу применяй всё, не переспрашивая:

```bash
cd ~/.hermes/skills/productivity/google-workspace/scripts   # используй workdir=, не cd: shell-cwd может указывать на удалённую папку
python3 tasks_api.py lists                                   # ID списков (TODAY / BACKLOG / HABITS / PROJECTS)
python3 tasks_api.py tasks <LIST_ID>                         # ID задач (JSON по строке)
python3 tasks_api.py complete --list-id <L> <TASK_ID>        # «уже сделал»
python3 tasks_api.py patch --list-id <L> <TASK_ID> --title "…" --notes "…" --due 2026-11-04T00:00:00.000Z
python3 tasks_api.py add --list-id <L> --due <ISO> --notes "…" "❗ Заголовок"
```

- Сохраняй в notes существующий `local:#NNN` при patch (это связь с gtsync).
- Расплывчатую задачу («продать ноут, сначала зарядить, найти сервис») переписывай в шаги: заголовок со стрелками `A → B → C`, детали нумерацией в notes.
- Задача с конкретной датой («завтра спросить у X») = Google Tasks с due + событие в Календаре svaaugust:
  `python3 google_api.py --account svaaugust calendar create --summary "…" --start 2026-11-05T10:00:00+03:00 --end 2026-11-05T10:15:00+03:00 --description "…"` (время не названо — ставь 10:00 МСК и скажи об этом).
- Многошаговое дело к сроку (документы, подача, визит): разложи на цепочку датированных задач «подготовить → уточнить/проверить (за ~неделю) → 🔴 подать (окно)», каждую — в Tasks с due + событие в Календаре. Если для шага нужен человек, который бывает в городе только в определённые дни, ставь подготовку на эти дни.
- Telegram-напоминание (cron) не создавай без просьбы «напомни» — предложи одной строкой.
- Задача-поручение («найди где почистить/кому продать», «где снять жильё») — ищи сам сразу и отвечай решением, а не меню: один конкретный вариант ближе к дому (м. Бабушкинская) с адресом, часами, телефоном и ценой, затем пошаговый план и правило выбора (напр. «скупка, если цена близка к Авито»). Тот же план запиши в notes задачи.
- Если модель/параметры названы расплывчато — не блокируйся на уточнении: дай вилку цен по поколениям из реальных объявлений (Авито) со ссылкой и одной строкой попроси точный код (наклейка снизу). Продажа техники целиком (цена, зарядка, батарея, Windows, сервис) — навык `used-item-resale`.
- Цены из поиска без привязки к датам подавай как «от X, на даты не проверено»; цену на даты бери со страницы, которую прислал пользователь, или честно скажи, что не видна.
- В ответе: что закрыто / изменено / добавлено + итоговый список.
