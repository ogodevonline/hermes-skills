# lead-platform — постмортем первого живого показа (23.09.2026)

Показ потенциальному клиенту (Лима, Нукус, по телефону, вечером) провалился.
Это НЕ «случайно сорвалось» — показ подтвердил диагноз 10.09 живым клиентом из ЦА.

## Что реально сломалось (проверено, не догадки)
1. **Цепочка demo слишком хрупкая**: интернет клиента (Нукус, лимиты) → домен
   `24ghost.online` → TLS/варнинг браузера → Telegram-бот → телефон. Рвётся любое
   звено — демо мертво. Уведомление в worker-бот (главный вау-момент) не дошло.
2. **«Красный экран про мошенников»** — диагностика в
   `references/https-red-screen-diagnosis.md`. Факты: домен чистый (Let's Encrypt
   валиден до 10.12, Safe Browsing «не найдено небезопасного контента», IP не в
   блэклистах), но домену <6 мес (создан 06.04.2026) и зона .online =
   репутационный soft-варнинг Chrome (снимается кнопкой «назад» — признак
   репутации, не malware). + найден реальный баг: `www.24ghost.online` падает по
   TLS handshake (нет cert в Caddy) → чинить немедленно.
3. **Лима: «надо изучать с утра до вечера», «дохуя всего с непонятными
   надписями»** — то же, что зафиксировано 10.09 (язык платформы, нет первого
   шага, две двери). Подтверждено НЕ-технарем из ЦА.
4. **Её вывод «проще записать 3 клиента в месяц самой»** = граница ценности:
   платформа окупается там, где записи ТЕРЯЮТСЯ (поток, очередь, несколько
   мастеров), а не при 3–10 клиентах в голове/директе. Сузить ЦА показов.
5. Методическая ошибка процесса: первый показ делала не-продавец (жена) —
   одновременно ученик + продавец + техподдержка, по телефону, вечером, без
   скрипта. Продавать надо результат мастера (запись → ✅ одним тапом),
   админку на демо НЕ показывать.

## Принятые решения (23.09)
- **Telegram-видеозвонок/живой показ клиенту из Нукуса — ЗАПРЕТ** (Василий:
  «звонок это проблема в сети всегда»). Сеть клиента = условие задачи, не помеха.
- Формат продажи: **видео-демо** (записать ОДИН раз у себя: телефон в руках,
  4 действия — визитка → сам записался → уведомление ✅ → в календаре; ~2 мин,
  480p, ~10–15 МБ, смотрят офлайн) + **стипы** (3–4 скриншота прямо в сообщение
  для совсем слабой сети).
- Настройка без обучения: Василий (или Hermes) сам заводит систему клиента
  (услуги/график/мастера) и присылает скрины УЖЕ ЕГО данных; клиенту остаётся
  нажать ✅. Никакого «учить админке вечером перед сном».
- Роли: жена/сотрудники — тестировщики и первые пользователи, НЕ продавцы.
- Продуктовое требование: лёгкость на 3G/слабом интернете (замерить бандл
  лендинга/админки, время до первого экрана).
- Домен продажи: менять с `.online` на `.ru`/`.com` за Cloudflare; прогреть
  2 недели (Search Console/Яндекс.Вебмастер + реальные записи пилота).

## Вывод для будущих показов (правило)
Живой URL в руках клиента с плохой сетью = лотерея. Показ = асинхронный
(видео + стипы), настройка = без участия клиента, цель демо = цена и решение,
не «разобраться в приложении».
