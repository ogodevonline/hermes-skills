# Uzbekistan Service Finder — Поиск мастеров и услуг в Узбекистане

## Когда применять

Пользователь просит найти мастера/сервис/услугу в Узбекистане (особенно в регионах: Нукус, Каракалпакстан, малые города). Специфика: культуры онлайн-отзывов нет, много агрегаторов-пустышек.

## Стратегия поиска (по приоритету)

### 1. Прямые контакты
- **Instagram** — ищи `@<profession>_<city>` (plumber_nukus, master_tashkent и т.д.) — часто указывают телефон в bio
- **perevozka24.uz** — реальные телефоны мастеров, есть разделы `ts-rent_stroy-brigady` и `ts-<специальность>`
- **Телеграм-каналы** — `@santexnika_nukus`, `@rabotavnukuse`, `@nukus_rabota1` и аналоги

### 2. Площадки с объявлениями
- **OLX.uz** — основной источник. Номера телефонов скрыты за JS. Используй зеркало `uzik.org` или `bizorg.su` для просмотра контактов
- **BirBir.uz** — может блокировать (403), но иногда отдаёт контакты
- **Glotr.uz** — есть категории по регионам, мало объявлений для Каракалпакстана (обычно 0-1)

### 3. Агрегаторы-пустышки (НЕ звонить)
Эти сайты — просто колл-центры, которые перепродают заявки. Телефон начинается с **+998-71** (Ташкент). В Нукус никого не пошлют:
- PFACT (pfact.ru)
- ACBANK (acbank.ru)
- ief-spb.ru
- adaware.ru
- avtosani.ru
- jcbbscn.com
- uti-note.ru

### 4. Магазины (живая рекомендация)
Зайти в профильный магазин (стройматериалы, сантехника), купить что нужно и спросить кого из мастеров рекомендуют. Пример: **«Мир Сантехника» в Нукусе (91-385-03-30)** — рейтинг 4.7 на Яндекс Картах

### 5. Telegram-чаты
- `@nukus_rabota1` — Работа Нукус (можно спросить «кто нужен?»)
- `@rabotavnukuse` — Работа в Нукусе
- `@santexnika_nukus` — канал про сантехнику Нукус
- Через поиск `tg-cat.com` или `tgpulse.com` по ключевым словам

### 6. Бизнес-каталоги
- **Yellowpages.uz** — в разделе Нукус толком нет частников, только госорганизации
- **Top.uz** — пусто для Каракалпакстана
- **Flagma.uz** — часто recaptcha
- **Prom.uz** — для b2b, не для бытовых мастеров

## Алгоритм поиска в сессии

```
1. Поиск в vault/gms — вдруг пользователь уже спрашивал
2. web-tools search "<profession> <city>" — общий запрос
3. web-tools search "<profession> <city> телефон" — номера
4. Извлечь топ-5 результатов через web-tools extract
5. Проверить perevozka24.uz — там реальные номера
6. Проверить uzi.org — OLX-зеркало с номерами
7. Проверить Instagram — @<profession>_<city>
8. Проверить Telegram — @<profession>_<city>
9. Агрегаторы с кодом 71 — помечать как call-центры
10. Выдать пользователю: таблица контактов + рекомендации
```

## Pitfalls

- **OLX скрывает номера** — не трать время на browser_navigate для OLX, сразу иди на зеркала (uzik.org)
- **Большинство агрегаторов — пустышки** — код 71 (Ташкент) = колл-центр, не местный мастер
- **perevozka24.uz** — номера могут быть частично скрыты (заменены на *), но последние цифры видны
- **Instagram** — может вернуть 429 Too Many Requests через extract, используй browser_navigate если нужно
- **Отзывов нет** — это норма для малых городов Узбекистана. Не обещай пользователю что найдёшь отзывы. Вместо этого предложи стратегию: позвонить всем, сравнить ответы, спросить в магазине/чатах

## Проверка мастера по телефону (для пользователя)

Рекомендовать задать 3 вопроса:
1. «Что конкретно будешь делать и сколько по времени?» — профи отвечает чётко, халтурщик мямлит
2. «Цена фиксированная? Или будут доплаты?» — фикс = ответственность
3. «Гарантия? Если через неделю потечёт — приедешь бесплатно?» — хороший мастер даёт гарантию
