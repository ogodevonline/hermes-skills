# Hermes Hub

Единый пульт управления системой Василия.

**CLI:** `hermes-hub`
**Чат:** команда `/hub`

## Что собирает

1. **Задачи** — из SQLite (`~/.hermes/tasks/tasks.db`): сегодняшние pending + просрочки + сделанные
2. **Цели** — из `~/.hermes/life/goals.yaml` (6 активных целей, проверка linked_tasks)
3. **Сферы** — из `planning.py --json` (тренды, просадки, алерты)
4. **Вечные хвосты** — задачи с 5+ переносами
5. **Рекомендация** — 1 строка с главной проблемой

## Вывод

```
📊  HERMES HUB  ·  2026-05-08

📋  5 задач  ([H] 1 · [M] 3 · [L] 1) ✅2 ⚠️1 просрочка
🎯  6 целей
📈  6 сфер  🔻2 просадки
    💪 Здоровье/Спорт: 4/10 🔻

⚠️  ВЕЧНЫЕ ХВОСТЫ (≥5 переносов):
    [35] english-lesson  (перенос #7)

💡 Просрочки по сферам — запланируй действия
```

## Интеграция

- Уже в `~/.local/bin/hermes-hub`
- Можно встроить в `morning-brief-pipeline` как блок
- Можно вызвать по расписанию (cron)
