# Календарь месячных Лимы

**Файл календаря:** `~/hermes-vault/Areas/Contacts/people/лима.md`

**Справочник по нормам:** `references/menstruation-norms.md` — проверенные источники (Гемотест, ЦАМ): длительность 3–8 дней, цикл 24–38 / 21–35, нижняя граница нормы 3 дня. На вопросы о нормах отвечать по файлу, не из головы.

Когда Василий говорит «у Лимы начались месячные / месячные» — зафиксировать дату. Ведём историю начал, считаем цикл, показываем ожидаемую следующую дату.

## Когда использовать
- Василий сообщает о начале месячных Лимы → записать
- Василий сообщает об окончании → записать длительность
- Василий спрашивает «когда у Лимы следующие?» → посчитать и ответить
- Утренний/вечерний бриф → если ожидаемая дата близко, можно упомянуть (аккуратно, по контексту)

## Автонапоминание (обязательно, настроено 26.08.2026)
Василий: «проверка через 2 дня, потом каждый день напоминай, чтобы я спросил у Лимы как с месячными».

Работает через **сторож-скрипт** `~/.hermes/scripts/lima_cycle_reminder.py` + cron `Lima cycle daily check` (каждый день 12:00 МСК, no_agent):
- Скрипт читает календарь, находит последнюю запись без длительности
- Первые 2 дня после начала — молчит
- С 3-го дня — напоминает ежедневно в 12:00: «спроси как у неё, закончились?»
- Как только в календаре записана длительность (окончание отмечено) — молчит автоматически

**Ничего создавать/удалять при каждой записи не нужно** — скрипт сам считывает состояние из файла. При новом начале месячных достаточно обновить файл календаря.

Если Василий скажет «закончились» / «длились N дней» → записать длительность к последнему началу — сторож сам замолчит.

## Процедура записи
1. Проверить текущую дату: `TZ=Europe/Moscow date +%F`
2. Открыть `~/hermes-vault/Areas/Contacts/people/лима.md`
3. Добавить строку в таблицу `| Дата | Длительность | Комментарий |` (длительность можно уточнить позже или оставить пустой)
4. Пересчитать **цикл**: разница в днях между последними ДВУМЯ началами (если записей ≥2). Записать среднее/последнее значение в «Цикл»
5. **Ожидаемое следующее начало** = последнее начало + цикл (если известен). Если нет — «посчитается после 2-й отметки»
6. Обновить `updated:` в frontmatter
7. Закоммитить: `cd ~/hermes-vault && git add -A && git commit --no-verify -m "lima cycle YYYY-MM-DD" && git push`

## Ожидаемое начало (прогноз)
- Цикл известен (напр. 28 дн): следующее = последнее начало + цикл
- Показывать дату и «примерно» — цикл может плавать ±3 дня
- Если ожидаемое начало просрочено на 5+ дней — можно мягко упомянуть в брифе

## Pitfalls
- Не выдумывать длительность месячных — спрашивать или ставить «—»
- Не путать с карточкой контакта — календарь в том же файле, секция `## 🌙 Менструальный календарь`
- Даты — МСК (сервер UTC)
- GOTHAM hook может блокировать commit → всегда `--no-verify`
- Если Василий говорит «закончились» — записать длительность (кол-во дней) к последнему началу
